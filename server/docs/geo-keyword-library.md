# 品牌拓词库

商家后台 → 资产 → 拓词库。拓词独立于 AI 创作台，按当前品牌管理多张词库。GEO侧栏不再保留独立入口；原 GEO `#keywords`、`#questions`、`#ai-keywords`、`#manual-keywords`、`#keyword-index` 和 `#keyword-library` 均转到资产的 `finished=keyword` 分类，保留租户与品牌。

新建词库必须显式选择关联品牌商，由服务端校验该品牌属于当前商家；已有词库不能直接更换品牌，以免关联词题被隐式迁移。三种拓词方式都先选择目标词库：关键词指数查询（当前仅入口，用户确认稍后提供接口）、AI拓词、手动拓词。手动方式支持六组词的笛卡尔组合预览（最多1000条）及直接录入，勾选后每次最多100条入库；预览不保存、不调用模型、不扣费。

AI创作顶部工具栏提供“AI拓词”快捷入口，在当前页面弹窗中先选目标词库，再使用同一套模型配置、费用确认和结果入库流程，保存后可直接带入当前创作。打开/关闭弹窗保留原有稿件和主题。

AI创作的“选择词库”使用弹窗，左侧集中提供品牌商筛选、词库列表及“＋”新建词库入口；移除弹窗顶部重复的介绍、选库下拉和新建按钮。可选择整库或词题。采用其他品牌词库时同步切换写稿品牌与资料，并使用目标品牌的独立草稿范围；原品牌草稿继续保留。也可自行编写主题。

词表名称及核心词/方向保存在原 keyword 类型编辑资源中，词题保存在原问题表，通过 keyword_group_id 归类，无数据库迁移。历史未分组问题及归档词表的词题显示为未归类，不迁移或删除历史资料。不同品牌、商家、租户继续隔离；不同词表可以有同一词题，同一词表内去重，导入不会挪走其他词表的内容。

可新建和编辑词表、手工按行录入或导入 UTF-8 文本（每次1至100条，每条最多500字，文件不超过256KB）、搜索和导出本页词题、编辑词题和意图。编辑使用哈希并发校验；实际改写过的词题不再标记为原 AI 结果。

AI 拓词默认引用词表方向和当前品牌知识，生成10、20或30个客户自然问题。复用原 DeepSeek 文本能力、费用确认、价格指纹、幂等请求和持久化队列；结果显示真实状态，用户勾选后保存到当前词表。每次1次模型调用，最多输出4096 Token，按原实际输入/输出计费。不生成搜索量，不自动创建诊断或发稿任务。

写稿保留 GEO写稿、爆文改写、批量创作三个模式。通过“选择词库”弹窗带入所选词题或整张词库，一次最多100条；可以单选、合并，或勾选1至3条批量生成。也可完全自行编写本篇主题；手动修改主题时清除旧词题选择，避免把旧问题强加到新主题。打开/关闭选库弹窗保留当前稿件。

新增接口：`keywordLibrary`（品牌词库、计数、分页词题、最近20项拓词任务）、`keywordLibraryAdd`（校验来源并按库去重）、`keywordLibraryUpdate`（权限和并发检查后编辑）、`keywordLibrarySave`（显式关联品牌商的新建/编辑）、`keywordManualPreview`（指定词库的免费组合预览）。均复用商家应用授权、同源写入校验及品牌归属。

验证：`tests/geo-keyword-library.integration.php` 覆盖22项分类、隔离、去重、搜索、归档兼容和编辑检查；`geo-keyword-methods.integration.php` 覆盖18项显式品牌关联、手动组合和目标库检查；原 `geo-creation-studio.integration.php` 的44项任务和原账本检查继续通过。`geo-keyword-routing.contract.cjs` 覆盖资产位置、跨品牌采用及请求范围。数据使用事务回滚，无外部付费调用。
