# GEO Semi Design 重构

用户确认四板块方向，并重申所有算力沿用平台现有标准。直接接入 `/ai/geo`，不使用独立演示数据。

## 页面结构

- 工作台：真实创作/发布统计、操作流程、快捷入口和最近任务。
- AI创作素材库：关键词、写作标题、企业画像图库、企业知识库；写作指令、文章分类、AI写作任务、文章列表；全网/批量爆文复刻；AI拓词、手动拓词。
- 媒体发布：B2B行业网站/自动任务/联系方式/发布记录；网站媒体发布/任务/投稿记录/收藏；自媒体大V发布/投稿记录/收藏；个人账号授权/任务/记录；官网SEO站点/任务/记录。
- 数据中心：真实业务报表、可见度诊断/报告、带截图查询/记录、关键词指数、原算力明细。

参考菜单通过已登录 `geo.981.ink` 侧栏读取。另核对首页流程、写作任务表单（关键词、图库、知识库、指令、数量、审核）、网站媒体筛选和报表（平台、主词/拓展词、来源、查询时间）。供应商缺失功能保留完整入口及明确开通要求，禁止伪造连接、排名、截图、搜索量。

## 实施顺序

1. 扩展商家资料资源 CRUD、关联关系和真实报表接口；每次读写验证 tenant/user、上级现有权限和版本。
2. 以 React 18 + Semi 2.104.0 实现正式页面组件，构建为本地静态资源；沿用原路由和会话，GEO 使用独立全屏工作空间。
3. 复用现有生成队列、算力结算、素材图库及海讯社订单流程；新增页面不定义价格或钱包。
4. 统一分页、筛选、表单、抽屉、弹窗；Semi 局部主题和浮层容器跟随现有主题。
5. 验证隔离、资源关联、并发修改、报告口径、旧GEO回归、生产构建以及深浅/窄屏界面。

## 架构边界

资源资料为服务器持久数据；旧品牌/问题/文章/素材/任务/证据继续复用。自有账号和CMS凭证仍仅允许管理端配置；商家页面不得提交或读取上级密钥。媒体采购调用现有海讯社通道，最终订单仍需核对现有报价。消费者端自动监测、B2B自动发布、账号直发、CMS发布、关键词指数在正式供应商契约缺失时禁用执行。

## 验收

四入口和所有参照子菜单均可直接进入；编辑、筛选、分页、返回和页面刷新可用。没有服务时显示原因、无假成功；资料记录不扣算力。付费任务只走原队列与流水，重复提交复用请求键。供应商未开通时不调用。所有统计只基于本商家真实数据，人工证据与自动检测分开。

## 专属工作空间（追加需求）

从商家平台 GEO 入口进入 `/ai/geo?tenant_id=…`，参照短剧的独立布局：专属左侧四板块和子菜单、顶部账号及算力、独立内容滚动区域、底部返回主平台入口。浏览器刷新保留 hash 子页面。`geo-standalone` 仅在 GEO 路由生效，退出时恢复原平台导航。复用原生商家账号控件，外观、登录和余额均使用原系统；无第二套会话或计费。
