调研日期：2026-10-16。参考：用户已登录的小魔推 `https://xiaomotui.com/#/seniorEditor`，仅以可见界面和官方 API 文档为证据；不提取登录凭证、不提交付费生成、不复制第三方素材。目标是在本系统原商家剪辑入口内实现相同业务流程，沿用系统主题和商家数据隔离。

- 用户确认：自己的阿里云和火山引擎账号已存在，相关服务尚未开通。

## 界面直接确认的功能

### 一键成片

- 镜头素材池，可添加素材，设置转场与滤镜。
- 目标成片时长区间，默认10～15秒，数字控件范围1～40秒。
- 高级设置含显示字幕、字幕/花字/特效应用到全局、无需字幕/全局字幕。
- 音量调整、背景音乐池（最多100）；画幅9:16/16:9/1:1，帧率25/30/60，颜色调整。

### 批量混剪

- 共享素材池与“消除原声”开关，默认开启。
- 合成规则：抽取镜头数量区间，初始1～1个；单镜头抽取时长区间，初始3～5秒，显示预计成片时长。
- 画面速度初始1.0；配音音量1、背景音乐音量0.5、配音语速1。
- 背景音乐最多100、标题文案最多100、贴纸最多50；标题支持批量设置。
- 背景填充、颜色、画幅、帧率、预览，保存为模板，立即剪辑。

### 分镜剪辑

- 默认三个镜头组；支持增加镜头组、镜头组模板市场。
- 视频封面池最多20个；每个镜头组各有素材池与时长配置，支持转场/滤镜。
- 分镜字幕与全局字幕二选一；每镜头各维护配音，支持添加配音演员。
- 合成时长可按视频时长或配音时长（当前默认按配音时长）。
- 共享音乐、标题、贴纸、音量、画幅、背景、帧率、颜色、预览、模板。
- 切换部分编辑模式有“当前素材配置可能不保存”的确认提示。独立调研页仅载入已有模板查看配置，没有修改、下载或向我们系统导入第三方素材。
- 已保存分镜界面截图：`runtime/local/evidence/xiaomotui-research/storyboard.jpg`。

### 脚本剪辑

- 已进入并确认独立的AI创作流程：生成选题 → 口播文案 → 拆解分镜。
- 生成选题有分析品牌战略、分析对标账号、分析对标视频三种来源。
- 参数含推广目的、文案风格、用户群体和生成条数；提供历史选题、换一换。
- 后续阶段、素材选择、字幕/配音编辑和任务提交规则仍待展开核对，不把尚未观察到的行为写成已验证。

### 转场与滤镜

- 各自支持随机开启、自选池随机抽取、效果预览。
- 已观察到数十种转场（含对角、擦除、溶解、旋转、模糊、遮罩等）及多款具名滤镜；具体效果不能仅靠同名下拉框宣称复刻完成，需核对云端特效资源与参数、逐项渲染验证。

### 素材、字幕、标题、配音和贴纸（已展开）

- 素材选择器沿用文件夹、标签、视频/图片切换、使用状态、合成/裁剪次数和AI分析状态；支持多选与本地上传。仅在独立调研页临时选择一个已有视频，未提交合成、未下载其文件到我们系统。
- 选择全局字幕会改变合成规则：单镜头秒数区间隐藏，显示“添加字幕”和“添加配音演员”；无需字幕时按镜头秒数区间采样。
- 全局字幕面板支持手动字幕或配音文件，字幕池最多100条，单条800字；支持字体、字号、颜色、文字高度、对齐、边框、背景、花字、字幕特效、导入。AI帮写、深度思考、改写、自动划重点单独属于模型增强能力。
- 配音演员可多选；分豆包大模型2.0与克隆人声，普通音色又有通用场景、趣味口音、角色扮演、视频配音、客服场景、1.0音色等分类。没有触发克隆或配音生成，没有复制第三方音色。
- 标题编辑器每条最多50字，支持多标题、导入、字体、字号、颜色、文字高度、对齐、边框、背景、花字，显示起止秒数（默认0～3秒）；独立于字幕。AI生成文案遇标点自动换行是界面提示，尚未付费生成验证。
- 画面速度滑块范围0.75～2，默认1。
- 贴纸支持展示镜头选择（全部/单镜头），每项上传最多2个文件；界面列出mp4/mov/jpg/jpeg/gif及多类公共贴纸。不能直接搬用第三方贴纸库或字体资产。
- 脚本历史选题可直接查看已有结果表，字段有选题名、目标用户/需求、前3秒钩子、核心画面、风险和依据；选择后需点击“开始写成口播文案”才继续。后续步骤有disabled先决条件，未提交任何新的模型生成，因此口播文案和拆解分镜生成后界面仍待验证。
- 音量与速度：配音音量0～3（默认1），背景音乐音量0～1（默认0.5），配音语速0.2～3（默认1），有恢复默认和预设操作。参考UI的语速范围与火山语音API范围不完全相同，不能直接把倍数传入百分比字段。
- 调色：对比度、饱和度、色相均为-100～100，亮度为-255～255，默认均为0；背景填充有纯色、拉伸模糊、图片/视频三种。
- 分镜组时钟按钮可打开“自定义镜头时长”开关。开启后的控件范围未验证，不能把我们系统自定范围称为参考系统限制。

### 模板、工程、预览和成片（已展开）

- 我的模板支持搜索、日期、分页；载入模板会回填完整模式及素材、字幕/配音、音乐、标题配置，可能切换当前编辑模式。参考模板可见3组镜头，分别有10/18/22条素材、各10条配音文案、5个音色、6条背景音乐及1条标题，证明是组合池而不是一次只配置一个文件。
- 工程列表有名称/日期筛选、卡片、重命名、查看、删除和分页。
- 工程详情分“批量预览”与“成片库”；当前每个工程最多100条预览。有总数、已生成预览、已生成视频、已删除预览、剩余预览计数。
- 有“生成预览视频”、单条“生成视频”，批量操作包括生成视频、重试、删除。只读查看了已有工程，没有提交新预览或成片任务。

## 官方文档证据

1. [阿里云提交剪辑合成任务](https://help.aliyun.com/zh/ims/developer-reference/api-ice-2020-11-09-submitmediaproducingjob/)：任务异步，支持时间线/模板；直接引用素材有OSS格式和地域约束，不能把本地 localhost 上传URL直接交给云服务。
2. [Timeline配置](https://help.aliyun.com/zh/ims/developer-reference/timeline-configuration-description)：视频、音频和效果的轨道结构。
3. [批量混剪准备工作](https://help.aliyun.com/zh/ims/use-cases/audio-and-video-editing-and-synthesis)：组合多个素材形成不同成片，仍由调用者定制时间线。
4. [IMS开通FAQ](https://help.aliyun.com/zh/ims/support/product-activation-faq)：IMS不会自动开通OSS/CDN；需配置访问授权和同地域输入输出；不要混淆MPS与IMS。
5. [视频剪辑计费](https://help.aliyun.com/zh/ims/video-clip)：现行计费依分辨率/模板而异，不足一分钟按一分钟计；还需核对IMS订阅。截图0.03元/分钟不能作为所有规格的统一单价。
6. [OSS数据处理概述](https://help.aliyun.com/zh/oss/user-guide/overview-50/)：视频截帧、事件与IMM集成；具体打包接口已在第9项核对。
7. [火山异步语音合成任务提交](https://docs.volcengine.com/docs/DoubaoVoice/Tasksubmission?lang=zh)：普通TTS与复刻音色资源标识不同，支持配音参数和可选时间戳；临时结果需要及时入库。
8. [声音复刻控制台开通](https://www.volcengine.com/docs/6561/1167802?lang=zh)：选择项目开通模型/音色服务；普通配音开通不等于声音复刻开通。
9. [IMM打包下载接口](https://help.aliyun.com/en/imm/developer-reference/api-imm-2020-09-30-createfilecompressiontask)：异步文件打包，官方说明当前支持打包、不是缩小文件体积的压缩；输入和输出同地域、需独立IMM项目与OSS授权。
10. [OSS视频单帧截取](https://help.aliyun.com/zh/oss/user-guide/video-snapshots)：`x-oss-process=video/snapshot`，时间单位毫秒，取封面可用0，私有对象需签名处理URL。
11. [火山录音识别极速版](https://docs.volcengine.com/docs/DoubaoVoice/recording-file-recognition-lite-http?lang=zh)：`/api/v3/auc/bigmodel/recognize/flash` 是与TTS不同的语音转文字能力；具体版本、文件限制与资源ID分别配置。
12. [火山方舟文本生成](https://docs.volcengine.com/docs/ark/responses-api-text-generation?lang=en)：AI脚本等可使用方舟文本模型，模型开通与语音服务开通分别处理。

## 接口落地边界

- 阿里云 `SubmitMediaProducingJob` 接受 Timeline，返回异步任务；`GetMediaProducingJob` 查询结果。采用同地域OSS输入/输出，不能将本系统的localhost素材地址直接提交。Timeline文档与该提交接口文档对外链支持的表述不完全相同，实施以所用提交接口的限制为准。
- Timeline的具体字段包括 `VideoTracks[].VideoTrackClips`、`AudioTracks[].AudioTrackClips`、`SubtitleTracks[].SubtitleTrackClips`；素材起止和时间线起止需要分别编译。特效/字体需核对资源映射，不能将参考界面中文名称直接当作云参数。
- 火山异步TTS提交：`/api/v3/tts/submit`，普通音色和复刻音色使用不同资源标识。返回音频及可选时间戳；临时结果须转存自己的OSS。原视频语音识别另走ASR，不与TTS混为一个接口。
- IMM `CreateFileCompressionTask` 与 `GetTask` 支撑异步打包；阿里云IMS、IMM是不同产品。打包下载需OSS授权和独立IMM项目。
- 第三方账号实际开通状态、套餐折扣、并发配额、现用云资源和内部API没有核实。截图只能证明列出了哪些平台及计费项目；我们自己的“服务均尚未开通”来自用户明确答复。
