# 视频剪辑页参考图优化

用户指定参考：codex-clipboard-88b89730-83cf-438e-b134-4d6ded23b716.png，1555×1011。沿用当前工程和API，仅整理已有页面。

- 人群与任务：商家从素材池组合视频，在同页配置字幕、时长、声音并预览；后续仍通过工程编排确认云合成。
- 视觉层级：素材空态为主要引导，顶部四个模式与操作集中，右侧白色卡片内为深色播放画面，下方三项补充素材独立展示。
- 领域：镜头、素材池、字幕、声音、工程、成片；颜色取自参考的紫色、白色、淡灰紫、深灰播放框、金色模板入口、绿色贴纸图标。签名为紫色叠层播放卡片的空态插画。
- 用原字体与主题变量，标题24/18/14px层级，4px基础间距，主卡20px内边距、14px卡片间距、18px圆角。浅色用白色内容面板与淡紫画布，深色仍继承原主题，播放画面保持深色。
- 延用商家原侧栏、搜索、通知与账户；标题添加在当前页原顶栏空白区域，离开页面清理。使用现有 Feather 图标，新增同版本 monitor/clock/info/save；空态插画为单独透明图，不用CSS拼图。
- 核心操作不重建：素材选择/上传、四模式、画幅与帧率、字幕/音量设置、模板、工程、预览、编排和云合成确认流程复用；不新增付费调用。
- 预览区可继续收起；桌面双列，窄屏上下排列。当前素材计数及云接入状态使用真实数据。
- 验证：按参考图同尺寸捕获、组合对比；检查桌面和手机，以及素材选择、比例/帧率/字幕、弹窗、模式、工程入口和离开页清理。
