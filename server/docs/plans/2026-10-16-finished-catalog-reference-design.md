# 成品库参考页面修正

参考：小魔推已登录的 /Ai/video、/Ai/graphic、话题库。2026-10-16 实际读取页面与图文库创建弹窗。

根因：上一轮仅统一导航和数据入口，将原素材文件夹组件直接嵌入资产页，未实现参考的库概览。

保留 AI成品库平铺侧栏、顶部搜索、原生资产、既有归库 ID 和租户/商家隔离。三种成品库在原页面内独立展示，隐藏原资产筛选侧栏和多余分类 tabs。成片库使用卡片网格（名称、创建时间、使用上限、总数/已使用/剩余、视频管理、任务管理）；图文库使用共享表头列表（名称、内容数量、使用统计、创建时间、详情/添加/编辑/回收）；话题库使用简洁列表。筛选提供名称、创建日期及分页。详情在当前页面或弹窗中管理，内容编辑沿用现有接口。

视频与图文库增加每项最大使用次数，0 为不限；统计与限额以有效员工任务的已分配次数为准，取消任务释放可用次数。保存和任务分配都串行锁定商家，防止并发超额。现有任务数据参与统计。话题库不设使用上限。原框架生成、计费接口保持不变。

图文页另含图片库/文案库两个独立业务类型，以新增 kind=finished_image/copy 存储，不与原始素材或图文记录混合；文案库接入员工任务文案来源。邮件预警不放置无实际发送能力的按钮。既有认证服务号通知仍走任务页。

验收：布局、库筛选/分页、新增/修改/回收/恢复、内容详情/新增、视频任务入口、统计/限额/取消释放、跨商家隔离、原地导航和明暗主题。
