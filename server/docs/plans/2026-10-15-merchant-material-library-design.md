# 商家素材管理

用户已指定四张素材库截图并要求沿用现有系统风格，直接在既有商家素材库实施。采用参考的内侧文件夹栏、顶部类型切换、紧凑缩略图网格、底部选择与分页栏；采用本系统深色底、薄边框、绿色强调和原字体。无需更换外侧导航、品牌或门店页面。

素材类型含视频、图片、背景音频、旁白配音，并保留原图文、话题。新增每类独立的多级文件夹、名称/创建时间排序、素材搜索、真实引用状态筛选、标签库、多选、批量分组/标签/回收与恢复；视频和音频提供真实媒体预览。上传复用原存储驱动，并验证扩展名、MIME、大小、归属。纯展示不能假造分析/合成计数，NFC 与外部发布不在本次范围。

数据库新增文件夹、标签、素材元数据表，既有素材保留且默认显示于未分组。每次服务端查询、统计、分组关系、文件、批处理和标签操作同时绑定当前租户与商家，事务拒绝部分越权写入。种草卡仍只接受原视频/图文类型，音频与原图文内容分开管理。旧路由保持兼容，增加三条独立图片/音频路由。

验收覆盖真实保存/上传、标签和文件夹管理、移动分组、跨账号/跨租户与跨类型拒绝、批量原子性、回收恢复、旧业务回归；浏览器比较参考与现有深色 UI，检查空态、内容态、弹窗、预览、分页、窄屏与控制台。测试数据在验收后清理。
