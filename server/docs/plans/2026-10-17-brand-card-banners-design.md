# 品牌列表横幅卡片

按用户提供的品牌卡片参考图调整 `/ai/stores` 品牌列表。保留一个品牌多门店的结构，旗下门店继续使用表格。

- 顶部横向封面、与封面交叠的圆形标识，下面是品牌名称、行业与地址、知识完整度标签、企业介绍及三项真实统计。
- 卡片统计使用当前品牌的门店、核心关键词、内容文章数量。企业介绍来自同一份企业知识库，不另建数据源。
- 底部“查看详情”进入品牌空间，“管理品牌”打开资料编辑弹窗。标题与箭头也可以进入品牌空间。
- 品牌封面与标识独立上传、保存和移除。未配置封面时使用主题适配的品牌首字背景，不使用虚构的品牌图片或数据。
- 桌面三列、平板两列、手机单列；卡片、按钮、头像底色和编辑弹窗跟随平台的主题与皮肤。

## 数据与升级

`oem_merchant_brand.cover_file_id` 是可选图片引用，默认 0。`scripts/install-merchant-brands.php` 在已有数据库幂等补列；新建数据库使用更新后的品牌建表 SQL。

封面沿用现有素材上传接口与图片所有权校验，必须属于当前租户与商家。旧客户端不传字段时保留已有封面，传 0 时移除。品牌保存继续使用原有 revision 并发校验，不改计费或权限规则。
