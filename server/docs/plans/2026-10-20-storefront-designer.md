# 门店装修参考调整

用户指定参考：代理商后台 `https://ppk.siroc.cn/agency-v2/?plat_id=1&v=202607101659#/merchant` 内的“页面装修”。2026-10-20 已实查当前打开的编辑器，未修改或保存参考商户。参考截图：`output/playwright/storefront-reference.png`（工作区根目录）。

采用参考的三栏布局：左侧门店外观与主按钮；中间功能排序；右侧手机实时预览。桌面占用完整编辑区域，顶部保留返回、门店名称、保存状态与保存。小屏依次呈现配置、排序、预览，无横向页面溢出。白色卡片、浅灰画布、蓝色编辑操作，手机中的主题色独立于编辑器。

实现六种主题色、四种公共头图模板、自有图片上传、门店标语、大图／紧凑头图、收藏和团购显示开关、主推功能选择、平台色／黑色按钮；全部已有功能可上下排序、隐藏／显示、通栏／双列。选择隐藏的主推功能时取消主推，预览不能泄漏已隐藏项。手机内功能为装修展示，不触发第三方操作。继续支持撤销／重做、未保存离开确认与版本冲突提示。

使用既有设计表和登录／归属校验。新增 `storefront` 白名单配置保存外观、功能顺序、通栏及主推设置；功能可见性沿用 `features`，主题色沿用 `page.accent`，头图沿用 `header.background_file_id`。旧组件配置和模板不删除，提供“组件装修”入口。

本项目尚无公开门店落地页和已绑定的二维码／NFC 访问切换接口，因此“使用新版布局”仅保存布局选择，界面明确其为装修配置。不得宣称扫码切换已生效，不增加伪造的公开入口或平台授权。团购预览展示已有团购入口，不虚构折扣、价格或活动。

验证：配置规范化、合法值与非法值、功能排序／通栏往返、版本冲突、旧配置兼容；浏览器验证三栏布局、切换和预览、保存回填、刷新、离开确认、窄屏及先前闪退回归。
