# 海讯社媒体发稿接入设计与实施清单

用户已选择海讯社并要求总后台统一配置、OEM及两级代理按范围查看消耗和订单。实施目录为当前运行于8090端口的likeadmin-aigc，保留既有商家与后台外壳、明暗主题和权限体系。

## 已确认范围

媒体列表优先国内软文与自媒体；商家保存稿件、取得报价、明确确认费用后创建发稿子单。订单与账单关联，worker按同一我方单号提交或查单，发布回链作为交付证据。海讯社API不提供明确退款到账接口，供方退稿先进入待核实退款，平台持退款凭证确认后才返还客户额度；未受理的确定失败直接返还预扣。不把媒体发布等同于AI引用。

平台管理海讯社token/key、启用开关、零售加价及投稿预览公网域名；加密存储、读接口不回显，操作日志脱敏。OEM与代理没有配置或获取凭证的接口。平台可跨OEM查询；OEM限定当前tenant；一级代理当前直属和下级商家；二级仅当前直属；商家仅自己。列表、筛选、统计、详情、导出统一在服务端按当前归属查询。

货币以整数分保存，客户沿用1元=100算力换算，预扣和返还写原用户账户流水并使用行锁和请求幂等。供方成本仅总后台展示；下级显示客户订单金额和算力消耗。创建任务不代表外部受理；不确定提交只查原单、不创建新单；配置版本变化不自动切换供应商账号。
