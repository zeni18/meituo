# 单页 AI 创作台

用户已确认：沿用 AI 视频剪辑的单页组织方式，四种模式共用创作资料、选题池和右侧结果区。文章库、资料和任务使用侧栏，切换模式不丢失配置。

## 界面

顶部：GEO写稿 / AI拓词 / 爆文改写 / 批量创作；辅助入口为文章库、任务记录、更多资料。左侧从品牌与资料、主题问题池到写作配置，右侧为可编辑结果；底部展示选题数量和本轮费用确认入口。默认 GEO写稿。小屏将结果放在配置之后，保持所有操作可访问。

拓词支持 AI、手工录入、从问题库导入。结果保留意图和真实来源标记，支持选择、去重、合并为选题、加入当前创作和明确确认入库。写稿可引用同一组相关问题，批量每次最多3篇，遵守原队列上限。原先的多页面深链接映射到单页模式或侧栏，不删除原资料。

## 执行与数据

复用 GeoJobs、GeoArticleAgent 的持久化任务、结构化文章、版本修改和入库并发锁。增加工作台服务验证结构化写作要求、参考原文、写作指令/分类/关键词归属。模型输出仍使用提纲、正文和事实核查清单。拓词单独使用结构化问题任务，不改写诊断复测基准。

每轮明确确认现行模型价格，冻结价格指纹并在执行前复查；批量提交整体事务，重复请求不创建新付费任务。无自动重试或发稿。当前浏览器按商家与品牌保存未提交配置、选题和任务引用，服务器保存已提交任务和入库文章。

## 视觉与验证

运营人员需要连续完成选题到成稿，界面以左侧选题配置和右侧稿纸为主；延续品牌紫、纸白、墨色、浅灰、状态绿。紧凑配置与舒展正文形成层次，避免聊天空态、平铺工具按钮和分散页面。复用 Semi 控件、滑动侧栏和原主题变量。验证拓词到写稿、合并问题、批量计费幂等、资料隔离、手工编辑保存、旧链接、刷新恢复与手机布局，全部使用离线回调，不调用真实付费模型。
