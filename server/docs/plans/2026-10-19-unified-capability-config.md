# 接入能力配置合并 GEO

用户确认将 GEO 能力配置加入接入能力配置的左侧列表，适用于平台和 OEM。

- 左侧保留剪辑八项配置，增加 GEO 五项能力，并按“剪辑与通知 / GEO营销”分组。
- 复用 GeoAdministration 的同一表单渲染、独立 API 和权限。列表读取分别请求两套接口，一组无权限不阻断另一组。
- 平台保留逐能力 OEM 借权；OEM 保留自配、借用平台及代理授权。监测能力仍仅允许平台/OEM维护。
- 不迁移凭证、不变更授权或服务状态。未适配能力的配置仍禁用。
- 切换配置有未保存确认，当前能力记录在 URL hash。嵌入表单退出时销毁并忽略迟到响应。
- GEO 任务页保留；GEO 配置与海讯社接口不再显示独立菜单，旧地址跳转统一配置页。菜单合并发生在角色过滤之后，仅拥有 GEO 或海讯社查看权限的员工仍有统一入口，不新增任何业务权限。
- 总后台增加“媒体发布 / 海讯社媒体发布”，复用原 media.press 接口保存 Token/Key、启用、预览域名及加价，保留资源同步；OEM、代理不新增平台凭证权限。

验收以两端页面、剪辑/GEO切换、键盘切换、未保存取消/丢弃、只读待适配状态及旧路由为准；不保存业务配置，不调用收费接口。
