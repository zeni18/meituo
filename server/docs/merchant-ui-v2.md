# 商家端 UI 规范 v2

> 已被 `docs/商家后台改版规范.md` 取代（2026-10-22 起），本文件仅作历史参考，冲突处以新规范为准。

2026-10-20 定版。适用于商家端（`/ai/*`、`/login`）所有页面。短剧/漫剧、无限画布保持原样，不按本规范改风格，但 TP 叫法统一。
样板：设计画布「AI营销中台 · 商家后台样板」（工作台、AI 商品图、素材库、AI 视频剪辑）。

## 1. 原则

- **大厂的规整，创意平台的温度。** 结构、间距、字号、对齐全站一致；作品（图片、视频）是页面主角，界面退后。
- **颜色克制。** 页面约 90% 是黑白灰。强调色只用在：AI 生成按钮、当前导航图标、图表主序列、焦点、选中框。普通主按钮用近黑或白底。
- **高级效果按等级使用，不为省事降级。** 渐变、半透明、面积折线背景、堆叠卡片都可以用，但必须用在规定的位置（见第 5 节）。
- **只维护浅色主题。**

## 2. 禁止项（交付前逐条检查）

1. 线性图标放在浅色底框里。图标统一用实心（Semi Icons 填充款），不加底框。
2. 标签、状态、卡片用“浅色底 + 同色文字”表达。状态用“小圆点 + 文字”。
3. 主题色大面积铺开（浅紫底卡片、整块紫色背景、紫色描边卡片墙）。
4. 标题下放辅助说明文字。需要强调时用信息本身表达（数字、状态、期限、变化），不写一句话。
5. “图标 + 标题 + 一句描述”的等权卡片墙；到处是“开始创作 →”箭头链接。
6. 渐变文字、emoji、发光描边、装饰性插画占首屏。
7. 分段控件、标签文字溢出；操作入口（添加框、按钮）被裁切或显示不全。
8. 写“算力”或“积分”。统一叫 TP（见第 7 节）。

## 4. 字体与排版

- 字体：Inter（数字、英文，已自托管于 `/merchant/fonts/`）+ 系统中文（苹方 / 微软雅黑）。数字一律等宽（`.num` 或 `font-variant-numeric: tabular-nums`）。
- 页面标题 24/600；区块标题 18/600；卡片标题 16/600；正文 14/400，行高 22；说明 12，行高 18–20；指标数字 30–36/600。
- 间距基数 4：常用 8 / 12 / 16 / 20 / 24 / 32。页面左右边距 32（侧栏一侧 16）。
- 控件高度：桌面 36–40，主操作 40，生成按钮 40–48；手机 44。

## 5. 卡片等级

| 等级 | 外观 | 用在哪里 |
|---|---|---|
| 基础卡 | 白底、`--ui-shadow-card`、圆角 16、无描边 | 表格、表单、列表容器 |
| 数据卡 | 基础卡 + 数字下方渐隐面积折线；主序列用强调色，其余灰色 | 指标卡 |
| 焦点卡 | 靛紫网格渐变 + 高光，可叠 1–2 层堆叠卡 | TP 余额、当前生成任务、套餐；**每页最多 1 张** |
| 堆叠卡 | 多层错位堆叠，切换时位移/缩放 | 多张一组的作品、模板、多门店切换 |
| 作品卡 | 图片铺满、底部渐变遮罩里放标题；悬停浮出操作、图片轻微放大 | 素材库、作品库、生成结果 |

动效统一 200ms（图片缩放 500ms），尊重“减少动态效果”。

## 6. 导航与页面骨架

侧栏（`nav-v2.js`，12 项）：工作台｜创作：AI 工具、图像创作、视频创作、数字人、视频剪辑｜内容：素材库、作品库｜营销：GEO 营销（GEO 诊断、AI 创作、媒体发布）、门店营销（种草卡、任务发布）、自动化计划｜品牌：品牌与门店｜常用（用户固定的工具）。
新增页面先在 `nav-v2.js` 的 `GROUPS` 和 `activeKey()` 里登记，不在侧栏额外插入入口。

页面骨架四种：

1. **概览型**（工作台、品牌概览）：标题行 → 焦点卡 + 数据卡 → 常用 → 两栏（趋势 / 进行中）→ 最近作品。
2. **列表型**（素材库、作品库、种草卡、任务、门店）：标题行（主操作在右）→ 下划线页签（带数量）→ 卡片内：筛选工具条、列表/网格、分页；多选后底部浮出深色批量操作条。
3. **创作型**（各 AI 工具）：左配置卡 360–400px（底部固定“预计消耗 + 生成按钮”）+ 右结果卡（本次 / 历史）。
4. **编辑器型**（视频剪辑等）：主导航收成 72px 图标栏；左素材、中编辑区、右实时预览 + 全局设置；唯一的生成按钮在右上角并显示数量和 TP。

## 7. TP

- “算力”“积分”统一显示为 TP。金额显示为 **TP 图标 + 数字**（如 `⬢ 40`），单独作名词时写 “TP”（如“TP 账户”“消耗 TP”）。充值换算不变：1 元 = 100 TP。
- 图标是字体字形 U+E000（`TP Glyph`），任何文字里写 `\uE000` 即可显示；`tp.js` 会自动把页面上的“40 算力”转换为图标 + 数字。新代码直接输出 `\uE000 40`，不要再写“算力”。
- 只改显示，接口字段、价格、数据库不变。
