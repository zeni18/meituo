# 海讯社一键同步与服务器定时任务

## 使用方式

总后台 → 接入能力配置 → 海讯社媒体发布 → 媒体资源同步 → **一键同步全部**。

同步全部 15 类资源，页面显示每类数量、状态和失败原因。任务保存到数据库，关闭浏览器、刷新页面不影响执行。失败页最多自动重试 3 次，其余类别继续同步；完成后可点击“重试失败类别”续传。服务器重启后，过期任务租约自动恢复。

每页最多 500 条，按类型和供方 ID 更新已有媒体，保留本地 ID 与历史订单引用。只有完整获取成功的类别才会停用本次未返回的旧资源，失败类别不进行这一处理。目录在同步期间改变或分页重复时会提示重试，不会把缺页当作完成。

同步保存名称、地区、分类、报价、发布要求、供方状态与不同类别的详细业务字段。所有类别可以保存；商家媒体选择和费用核对仍只开放国内软文、自媒体，其余类别需要单独对接发布流程。同步本身不创建订单、不充值、不扣减商家算力。

使用平台已保存且启用的海讯社配置，无需公网预览域名。只调整加价比例或公网域名时，已有媒体继续展示，商家价格即时重新计算；原报价需要重新确认。资源的供方价格、上架状态、同步时间及历史订单金额不会因此改变，也不会刷新报价有效期。进行中的同步会保留分页进度，以新配置重试尚未提交的一页。

更换 Token/Key 时，旧账号媒体不会沿用，需要重新同步；停用接口会阻止同步任务继续写入，重新启用后可手动开始新批次。

## 部署

在现有项目目录执行兼容安装（保留原凭证、订单和资源）：

```sh
php scripts/install-press-resource-sync.php
```

全新安装或完整升级也可使用原 `php scripts/install-haipress.php`，已包含同步表安装。

在服务器进程管理器中添加常驻任务，工作目录设为项目根目录，使用本项目 PHP 8.2，开启退出自动重启：

```sh
php think media-press:sync --work
```

这项进程用于执行后台按钮创建的任务。只消费已有任务，没有任务时不会请求供方；它与发稿订单的 `media-press:work` 是两个不同进程。Web 与同步进程必须使用同一数据库、环境配置与加密主密钥。

## 宝塔定时任务

建议每日凌晨 03:00 同步一次（时区以服务器配置为准）。创建“Shell 脚本”计划任务，替换下列项目路径，并确认 PHP 路径与部署一致：

```sh
cd /www/wwwroot/your-project || exit 1
/www/server/php/82/bin/php think media-press:sync --all >> runtime/haipress-resource-sync.log 2>&1
```

该命令会创建全量任务并执行至结束；上次存在未完成任务时继续处理，不重建重复任务。后台常驻服务和定时命令可以同时存在，数据库租约确保同一时间只消费一页。无需在任务脚本内填写 Token/Key。

Linux crontab 等价示例：

```cron
0 3 * * * cd /www/wwwroot/your-project && /www/server/php/82/bin/php think media-press:sync --all >> runtime/haipress-resource-sync.log 2>&1
```

请使用有项目和 runtime 读写权限的运行账户，配置日志轮转。首次接入建议手动同步并确认结果后，再开启每日计划。本次仅配置本地同步服务，生产服务器的计划任务尚未创建。

## 查看和排查

```sh
php think media-press:sync --status
php think media-press:sync --once
```

`--status` 只查看进度；`--once` 消费一页用于排查，不会创建新任务。定时命令完成返回 0，部分失败、配置变更或异常返回 1；参数不正确返回 2。资源类别、错误与续传按钮可在后台查看。

## API 字段

资源目录通用字段包含 `sourceid`（资源 ID）、`name`（名称）、`region`（地区）、`classify`/`industry`（分类）、`costprice`（报价）、`remark`（备注）、`caseurl`/`case_uri`（案例）、`flag`（上架状态）、`deleted`（是否正常）、`recommend`（推荐）。文案类别以 `proficient_field`（擅长领域）代替名称。

| 类别 | 代表性详细字段 |
| --- | --- |
| 软文 | 入口链接、发稿速度、周末发布、链接要求、新闻源、收录类型、电脑/移动权重、入口级别 |
| 自媒体 | 账号认证、粉丝档位、阅读量档位、行业、周末发布、是否可发视频 |
| 海外发稿/母语 | 语言、国家地区、产品类型、翻译选项、交付时间等（按类别返回） |
| 微信 | 微信号、头像、粉丝/阅读档位、头条价 `costprice`、普条价 `cost2_price` |
| 微博 | 头像、认证类型、粉丝档位、直发/转发/任务价 `costprice`/`cost2_price`/`cost3_price` |
| 文案 | 擅长领域、推广渠道、字数、修改次数、交稿时间、写手类型 |
| 问答/友链等 | 回答数量、链接有效期、网站类型、权重、友链时间等（按类别返回） |

字段含义参考 [海讯社官方接口文档](https://oss.ebuypress.com/doc/open.html)。部分指标是区间编码而非实时精确数值，部分报价为 0 或负数表示该价格类型不支持。供方返回的原业务字段保存在本地详情中，购买和算力计费仍使用经过校验的金额。

媒体资源接口不提供现成稿件正文。稿件由本平台保存；提交发稿后，订单接口提供状态、发布链接和处理反馈。报价、资源状态、回链也不代表搜索或 AI 已收录。
