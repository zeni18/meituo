# 分镜卡片拖动排序

按用户圈出的分镜卡片区增加横向拖动，分镜剪辑及脚本剪辑共用该交互。

- 封面固定在最前；镜头卡片本体可拖动，右上显示手柄。拖动时有跟手浮层和落点线，靠近左右边缘自动滚动。
- 松开后移动整个镜头组，素材、配音、字幕、时长保留。专属贴纸的一基镜头编号同步重映射，全局贴纸编号 0 保持原值。
- 当前选中的镜头按身份保留，包括选中封面的情况。取消拖动或原地放下不改变工程。
- 保留上移、下移，增加 Alt + 左右方向键排序；Escape 取消拖动。重排使旧编排预览失效并标记工程待保存，沿用工程保存流程。
- 不改变云端适配、接口、权限或计费逻辑。新增辅助脚本在剪辑主脚本之前加载。
