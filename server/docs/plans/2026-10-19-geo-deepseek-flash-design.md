# GEO DeepSeek Flash 接入

用户已确定 AI拓词、文章生成、改写统一先接 DeepSeek Flash，并确认已有官方 Key、稍后在后台填写。采用官方直连作为新配置默认选项；既有市场上游配置保持兼容，不修改全局上游或其他应用的模型。

固定调用 `https://api.deepseek.com/chat/completions`、模型 `deepseek-flash`、非思考模式。问题与文章使用 JSON 输出，知识字段整理返回纯文本。密钥沿用 GEO 凭证加密与平台/OEM/代理逐项授权，不返回给商家。不自动重试收费请求，受理不明或输出截断保存原任务待核对。

计费复用 MarketTextModelRuntimeService 的任务、消费单、实际 Token 结算和自动化预算钩子。为服务端增加可选传输回调及执行范围，直连模型只在 GEO 专用范围中可选，避免其他应用误走该上游。登记 DeepSeek Flash 的原生输入/输出 Token SKU，默认下架且售价由管理员在原市场维护，不自动设定零价服务。后台带出产品 ID、密钥输入与配置说明；旧市场模型配置无需新凭证。

实施顺序：登记独立模型目录 → 服务端传输与原生计费扩展 → GEO配置/任务/自动化选择接入 → 后台配置表单 → 离线回滚验证、构建、浏览器验收。只有用户填写 Key 并配置售价后才可实测；本次不发起真实付费请求。
