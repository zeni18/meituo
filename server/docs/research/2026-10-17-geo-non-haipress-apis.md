# GEO 非海讯社能力调研

核对日期：2026-10-17。目标：国内商家 + 代理/OEM 交付。参照站为用户已打开的 AI宣传官。已读到主菜单及文章列表/分类、全网/批量复刻等子菜单；其部分 iframe 加载超时，未声称完整体验全部表单或付费功能。

## 能力覆盖与接入决策

海讯社的[公开中文资源开放文档](https://oss.ebuypress.com/doc/open.html)以媒体资源、资源状态、下单、订单查询和发布处理为核心。下表“未覆盖”指本轮核对的**公开 API 没有给出该契约**，不代表海讯社所有商务产品绝对没有此能力。

| 参照功能 | 海讯社公开 API | 本系统分工 / 独立接入 | 当前状态 |
| --- | --- | --- | --- |
| 网站媒体、采购型自媒体发稿、回链 | 已有对应接口 | 继续海讯社 | 已有适配，真实账号未开通 |
| 品牌与事实素材源力、问题库、文章库、任务与数据 | 非供应商基础业务 | 本系统按商家归属保存 | 已实现基础事实素材与任务闭环 |
| AI拓词、文章写作、改写、参考结构创作 | 未覆盖 | 现有文本模型市场 | 代码接入，须上架真实模型 |
| 网页检索、选题素材溯源 | 未覆盖 | 博查 Web Search | 独立适配与原生按次计费完成，待配置 Key 和价格联调 |
| 豆包/DeepSeek/千问/元宝等消费者端监测、提及/引用/竞品 | 未覆盖 | 优先核对 AIDSO 商务 API | 供应商候选已核实；正式接口契约与测试账号待取得，未实现自动监测 |
| 关键词指数、热度、搜索量 | 未覆盖 | 按数据平台签约，单独计量 | 未接入，不能用拓词或模型估计填充 |
| 自己的公众号、B2B 账号批量发布 | 未覆盖这种账号授权契约 | 各平台官方开放能力/合规服务商 | 未接入；不把媒体采购资源等同自有账号授权 |

## 国内监测：优先 AIDSO，先核实真实接口与计费

[AIDSO 官方](https://www.aidso.com/)说明其国内多平台监测、诊断、引用溯源和竞品分析能力；[官方 API Key 页面](https://geo.aidso.com/setting?type=apiKeyManage)提供开通入口。[官方监测说明](https://www.aidso.com/article/details/aisou-geo-monitoring-data-platform-core-features-NdtJVZ5Y.html)区分普通模型 API 与消费者端实际监测结果。

本轮结论：适合优先商务验证国内端监测；尚未取得正式请求/回执/计费文档，不能宣称已完成可用 API 对接或给出确定单价。没有使用搜索到的非官方源码或 Skill 路径作为生产契约。

向供方索取：支持的平台/网页或APP/地域、采集时间、问题与回答原文、原始引用列表和截图、任务ID与重试去重、失败/空回答/限流的计费、并发与完成时间、历史报告权限、OEM借权及转售许可、数据保留/删除约定、测试额度。统一我方商家任务号映射供应商任务号，先验证原文证据，再计算指标。

## 国内网页检索：博查

[博查官方开放平台](https://open.bochaai.com/)公开给出 Web Search 的 Bearer 鉴权、固定 POST 接口及网页检索结果格式。适合发现网页、摘要及来源；它本身不是豆包/DeepSeek端侧排名监测，也不是百度或抖音指数。

本轮已单独实现服务器适配，网页结果按字段白名单保存，使用原市场 per_call SKU 和原钱包/消费表。默认 Key 空、授权空、SKU下架。价格/预存政策依实际账号和商务合同，不给未经确认的单次人民币报价。

## 其他候选与边界

* 海外 AI 数据： [DataForSEO AI Optimization 文档](https://docs.dataforseo.com/v3/ai_optimization-overview/)包含 LLM 回答、抓取、提及和 AI 关键词数据。公开平台范围主要适配海外场景，不能代替本项目的国内端监测，暂不接入。
* 联网模型：[百炼联网搜索文档](https://help.aliyun.com/zh/model-studio/web-search/)描述联网及搜索来源能力，适合作为创作检索增强候选；这类模型调用不等于客户端可见度诊断，还需单独确认检索费用。
* 指数：[百度指数官方首页](https://index.baidu.com/v2/index.html)当前展示 API 体验入口，部分旧帮助材料又写不开放 API。按当前商务文档核实账号权限和数据用途，不能仅依据旧FAQ断言没有 API，也不能把页面调用接口当商业授权。
* 官网发布：[WordPress 官方 REST Posts 文档](https://developer.wordpress.org/rest-api/reference/posts/)提供文章创建/更新契约。仅适用于实际 WordPress 站点并需写入授权；不作为通用CMS或B2B接口。

## 验收口径

发稿回链、网页可检索、搜索引擎收录、AI回答提及、AI引用，是不同事实。记录应带平台/端/时间/样本问题/来源。提及率只在完成且有可信原文的样本上计算；空回答、失败、未知独立列出，不能作为未提及或成功优化。不能拿一次模型生成报告充当真实监测报告。
