# AI成品库归属与顶部搜索

依据用户最终指定的侧栏结构，新增与原“创作”一致的平铺分组“AI成品库”：资产、成片库、图文库、话题库。原始素材管理单独保留，用于剪辑输入的视频、图片、背景音频和旁白配音。

参考已登录的小魔推页面，确认素材管理属于视频创作，视频库／图文库／话题库属于 AI成品库，员工任务复用内容库。按用户指定，将本系统对应的视频入口命名为“成片库”。本次没有扩展参考平台的使用次数配额、预警邮箱或对外发布渠道。

## 实现

- `finished-library.js` 在原生资产页内容区域内挂载成品分类，保留右侧原生资产分类。点击成片库及其图文／话题标签只修改页内状态，不触发 Vue 路由导航、换页或原生资产重新加载。
- 视图选择保存在当前历史记录状态中，带完整 URL 校验；刷新可恢复，其他租户或 URL 不继承该状态。侧栏跨页面入口、旧成片和图文／话题地址仍可通过 SPA 路由访问。
- 原生“全部、收藏、上传、最近删除”切回时恢复原资产内容及筛选。原“资产”按钮移入 AI成品库分组，继续使用原生事件。
- 搜索复用原生搜索按钮，移到顶部通知图标左侧。保留搜索面板、工具筛选、键盘行为和主题能力，不复制搜索接口。
- 成片仍使用 `oem_film_library` / `oem_film_entry` 的视频引用；图文、话题仍使用原来的 `oem_material_folder` 类型及编号。没有复制文件夹、迁移文件或改变原生成接口与计费。
- 员工选片、文案／话题选库继续读同一套现有 API；为后续种草卡按成品文件夹选用保留这套来源。种草卡原有逐条素材关联逻辑未在本次扩展为新的对外发布流程。

## 验证

- 实际点击资产页成片入口、图文标签，地址保持 `/ai/assets?tenant_id=1`；刷新后保留图文选择。
- 侧栏 AI成品库恰含资产、成片库、图文库、话题库；各项高度 32px、外边距 0，沿用 12px 间隔。
- 搜索在顶部仅一个入口，侧栏为零；输入“图片翻译”正确筛选原生结果，Escape 正常关闭。
- 收起侧栏后组标题及文字隐藏，图标保留，没有旧二级菜单弹层；展开可继续点击。
- 图文／话题临时文件夹在员工任务对应选择器中可见，视频成片库与原数据一致。临时空文件夹已回收，未创建发布任务或发送通知。
- 返回全部资产后原有演示视频正常可见；原始素材页只有视频、图片、背景音频、旁白配音四类。
- 明暗主题均检查，控制台无错误。验收图：`runtime/local/evidence/finished-library/ai-finished-sidebar-light.jpg`。
- `tests/finished-library.contract.cjs` 验证原地切换、刷新状态、原生分类恢复、租户 URL 与无效类别；`tests/finished-video.contract.cjs` 的 8 项生成归库契约通过。新增及调整的 JS、中间件语法检查通过。
