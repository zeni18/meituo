# 资产中的品牌词库与三种拓词方式

用户要求：关键词指数查询、AI拓词、手动拓词三种方式都先选择词库；新建词库必须关联品牌商；AI创作弹窗选择对应品牌的词库进行生文。后续补充：拓词库放进资产。用户确认指数接口稍后提供，本次仅完成指数入口，不产生虚构数据或查询费用。

资产增加拓词库分类，GEO侧栏取消独立拓词库入口，旧链接转到资产分类。库页提供品牌商、目标词库选择器及新建入口，再展示三种方式。新建窗口品牌商必选，已有库不能直接换归属，以免迁移关联词题。复用现有品牌隔离和关键词分组，不迁移账本。

AI拓词保持费用确认与幂等任务；手动拓词支持六组词组合和直接录入、文本导入，组合预览不消耗算力，结果勾选后入库；指数入口展示目标库和查询词，接口未开通时明确等待接入，不提交查询或伪造指数。

AI创作使用“选择词库”弹窗：按品牌筛库、选择整库或词题后采用。跨品牌采用时同步切换写稿品牌，使用新品牌的资料和独立草稿范围；原品牌草稿保留。自行编写主题路径继续可用。
