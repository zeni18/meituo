# 门店装修工作台

目标：按已登录小魔推“门店列表→去装修”的三栏工作台实现，沿用现有商家主题和右上角账户入口。用户已授权照参考开发，直接推进实现和本地验收。

参考实查：两种基础样式、功能勾选、自定义链接、标题／副标题／背景图；自定义模式的八类组件、系统模板替换确认、导航拖入画布和导航新增弹窗、组件选中属性面板。截图在 `runtime/local/evidence/store-decoration-reference/`。未点击参考的保存或保存为模板。参考中的商家资料、品牌活动和业务图片不导入本系统。

实现方案：在现有门店路由内用 `store_editor=1&store_id=...` 切换完整装修工作区；保留返回列表和保存。左栏选择基础样式／功能或拖入自定义组件，中间手机画布即时预览，右栏编辑页面及组件属性。支持组件排序、复制、启停、删除、图文导航和魔方项编辑、商品展示参数、社群二维码／电话、悬浮链接；上传使用原商家文件服务，校验文件归属。模板归商家所有，可保存、应用和回收恢复，系统提供本地中性模板，不复制第三方实际活动内容。

数据保存在独立设计表，已有门店 ID、员工和素材关系不变。首次读取兼容旧装修草稿；保存使用版本号，避免不同标签页相互覆盖。所有接口继续执行登录、应用授权、同源写入与 tenant/user/store 归属校验。模板隔离同样在服务器执行，不依赖前端隐藏。

装修仅保存可预览的页面配置；不开放未授权的公开页面，不宣称已完成第三方发布／点评／关注、Wi-Fi 连接、支付或 NFC 激活。内置入口用于配置和展示，第三方能力仍按后续平台／OEM接入方案实现。外链仅允许 HTTP(S)，图片仅使用本商家上传文件；不执行任意 HTML／脚本。

验收计划：设计完整保存回填、版本冲突、跨商家访问、模板隔离与恢复、文件归属及 URL 安全检查；浏览器核对两种基础样式、自定义组件、编辑／排序／复制／删除、图片上传、保存／刷新、模板复用、明暗主题与窄屏。最终补充截图和实际检查结果。
