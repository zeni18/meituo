# 小米 HiUI 调研与 GEO 主后台整合

调研时间：2026-10-17。小米官方中后台组件库为 HiUI，由小米集团信息技术部推出；以 React 为基础，提供 TypeScript 类型、设计规范与主题定制能力，采用 MIT 许可。官方资料：

- 设计介绍：https://xiaomi.github.io/hiui/design/introduction/
- 官方仓库：https://github.com/XiaoMi/hiui
- 入门文档：https://xiaomi.github.io/hiui/docs/quick-start/

本次 npm 实际查询 @hi-ui/hiui、@hi-ui/tabs、@hi-ui/modal 最新发布为5.0.0，React peer范围 >=16.8.6，与当前 React18.3.1 相容。按需接入 @hi-ui/core、tabs、modal、button，真实使用其页签、工具按钮和工具弹窗。原有复杂 Semi 业务表单、数据表格、报价确认组件继续复用，避免改动接口和结算逻辑。主后台本身仍为原 Nuxt/Vue 外壳，GEO 使用现有 React 挂载机制接入，不新增独立后台。

接入时发现 @hi-ui/use-id 间接引用旧 uuid，已限定该子依赖使用11.1.1，保持其v4 API；没有改动其他业务包。构建通过，生产依赖审计不包含开发服务器依赖。

## 验证与边界

- TypeScript与Vite构建通过；geo-embedded、geo-navigation及8项主题同步契约通过，旧页面均有合法主页面或工具弹窗映射。
- 实际浏览器验证五个主入口、内容页签、创作弹窗、指令管理及其嵌套编辑（取消保存）、媒体渠道弹窗及记录页签、独立诊断和已有优化计划。
- 修正主后台原有裁切导致的弹窗遮挡：弹层挂到body旁独立主题容器，关闭页面即清理，避免滚动容器裁切。深色弹窗采用实色背景，防止透出底层文字；主题与原后台同步。
- 手机390px下页面宽度无横向溢出，工具弹窗宽358px且底部按钮在边界内。原用户浅色模式恢复，所有验收输入取消保存。
- 本次不调整计费、平台/OEM/代理授权、品牌隔离和供应商配置。未开通能力继续显示真实未开通状态，不模拟业务完成；未调用付费供应商。
