# GEO 参照功能与独立能力接入

继续当前 AIGC 二开项目。用户授权按侧栏参照系统开发；算力计费沿用现有后台；新增供应商配置由平台、OEM、获得授权的代理管理，OEM 可向平台借权。

参照系统已观察到：AI 可见度诊断/报告、素材源力、文章分类/列表、全网及批量爆文复刻、B2B/网站媒体/自媒体/个人账号发布、官网 SEO、数据报表、关键词指数、AI/手动拓词。远程内嵌内容多次加载超时，目前依据可读菜单核对功能，不声称已逐表单或视觉复刻。

推荐分工：海讯社仅负责现有媒体发稿交付；事实素材、问题、文章、任务和数据归属本系统；生成/拓词/改写通过现有 MarketTextModelRuntimeService；独立网页检索接博查。国内消费者端可见度监测优先调研 AIDSO，须取得其正式商用 API 契约、计量、账号与试测回执后启用，不能使用普通模型结果或其他平台结果冒充。关键词指数及自有账号/B2B/官网发布分别需要数据合同和账号/站点授权。

配置按 capability 与 tenant/agent 分开。OEM 自配或显式借平台；代理只能在 OEM 授权范围内使用或维护自己的配置，不可读上级密钥或更改平台借权。没有授权、停用、配置不完整均关闭；不做隐式回退。凭证服务器加密不回显；配置和借权有版本和审计。任务始终归商家 tenant/user，代理可见范围按当前商家归属实时计算。

生成进入持久队列，唯一请求键与输入哈希防止重复提交；执行前再次检查商家权限与配置版本。已开始且中断的请求不自动重发。生成记录原生应用任务/消费单 ID，算力余额、价格和结算复用现有模型市场。独立按次 API 必须绑定平台现有市场的 GEO per_call SKU，使用 TenantPowerMarketService 价格与 PointService/AiConsumptionLog，未配 SKU 不调用、不擅定价格。未知响应保留待核对，不自动退款或重试付费请求。

验证包括商家/OEM/代理隔离、撤权、配置密文、不完整配置不回退、幂等任务、执行中断、原生计费归属和无供应商时不可用。测试只用隔离本地账号和注入传输，不消耗供应商额度。
