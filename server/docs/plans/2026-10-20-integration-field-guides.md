# 接入参数配置步骤

范围：平台与 OEM 接入能力配置页的每个文本、数字、地址、多行参数和配置来源选择框。开关维持现有布局。

采用字段右上角“配置步骤”按钮打开短说明，内容包含入口、操作、填写规则与相关官方链接。统一帮助组件按能力及字段名选择教程；不读取凭证值、不发送网络请求、不参与表单提交或脏状态判断。使用独立按钮与对话框，支持键盘、Esc 关闭和焦点返回。

不采用常驻长教程，以免挤压表单；不只使用悬停提示，确保触屏和键盘用户可以查看。复用当前后台配色、边框和间距，不更换布局。

验证：检查各服务覆盖、开关教程不触发未保存提示、真实编辑仍提醒、GEO/媒体异步刷新后教程保留、窄屏无横向溢出。已有凭证不写入教程及截图。
