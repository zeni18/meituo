# 商家端主题统一

沿用用户已确认的浅灰背景、白色卡片、轻阴影和填充控件风格。统一原生创作应用与新增门店、素材、剪辑、成片库、任务发布、装修编辑器的面板和表单。共享语义变量位于 html，由现有主题引擎切换浅色、深色与皮肤；浮层通过根节点的变量引用获取当前颜色，避免复制打开时的颜色。

仅修改商家入口样式，不改变 OEM/平台样式或原业务接口。媒体播放区域、图片、装修手机画布、品牌图和状态色保留各自语义。原生 Element、vs-popover 和新增 ds-select 统一菜单背景、选中和焦点；弹窗/抽屉保留原尺寸及交互。

验证覆盖原生图像/数字人/音乐/工具/资产、任务发布抽屉、门店/素材弹窗、新旧下拉、浅深切换和皮肤变色。检查实际计算颜色、横向溢出、键盘与错误态及浏览器控制台。

实施中补充：原外观插件未监听其他标签页的保存事件。增加限定当前租户和账号的监听，复用原生外观刷新方法，保持业务草稿及皮肤预览保护。验收记录和维护说明见 `docs/merchant-theme.md`。
