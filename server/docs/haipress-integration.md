## 入口与职责

| 身份 | 页面 | 服务端范围 |
| --- | --- | --- |
| 总后台 | `/platform/integration/config#haipress` | 接入能力配置 → 媒体发布 → 海讯社媒体发布：Token/Key、启用、加价、公网预览域名、资源同步；原 `/platform/media/press/config` 自动跳转 |
| 总后台 | `/platform/media/press/orders`、`usage` | 全部OEM订单、客户消耗、供方成本；权限单独控制退款与恢复查询 |
| OEM | `/admin/media/press/orders`、`usage` | 当前OEM的订单和消耗；无供方成本、凭证、配置、退款接口 |
| 一级代理 | 同OEM路径 | 当前直属及当前下级二级代理的商家 |
| 二级代理 | 同OEM路径 | 当前直属商家 |
| 商家 | `/ai/media-press?tenant_id=1` | 自己的稿件、媒体选择、报价、确认下单、订单、发布确认/反馈 |

商家侧栏新增可用的“媒体发稿”。后续[GEO入口修复](merchant-geo.md)已将GEO营销接到`/ai/geo`，内容库支持按商家归属将文章转为发稿草稿并自动选中；转稿不扣费、不自动发布。稿件以不可变文本版本保存，修改时另建版本。每次选择1–20家媒体，每家形成一个子单。2026-10-17起媒体发稿在GEO内嵌切换，不再整页跳转；AI创作与网页检索已单独适配，须按[独立能力配置说明](geo-capabilities-configuration.md)开通实际模型、Key和价格。国内自动监测仍待独立供应商正式契约。

列表、搜索、日期、商家筛选、汇总、详情和CSV导出复用服务端查询范围；伪造tenant、merchant或order ID不会扩大权限。商家/代理迁移后，历史查询立即按当前归属校验。OEM及代理只能查询，不能代商家发稿或处理供方退款。平台员工也必须有具体菜单权限。

## 金额与状态

供方成本、客户零售价以整数分存储。加价以基点存储，100基点=1%；零售价向上取整至分。1元=100算力，例如供方12.34元、加价15%，客户14.20元，预扣1420算力。金额上限与报价签名由后端核验，前端改价无效。

客户确认后从原用户算力余额预扣，并写原算力流水；不是另建无关余额。发稿列表将“预扣中、已结算、已返还”分开统计；原通用算力流水仍按预扣/返还记账。已结算供方成本仅平台可见。本轮不实现OEM/代理差异加价或利润分账。

* 创建任务只表示排队；供方受理后仍保留预扣。
* 供方返回已发布且存在有效HTTP(S)回链后结算，结算不再扣第二次。flag=3显示“已发布待确认”；商家可确认完成或反馈，worker提交processON并继续查回执。
* 请求键保证下单重试不重复预扣。提交超时、断线、未知响应、查单flag=100都只查询原单号，不自动重新下单。
* 确定未受理、媒体下架、稿件过期等提交前失败自动返还预扣。供方明确拒绝下单（如余额不足）也返还。
* 供方退稿不等于现金已退款。平台核实海讯社退款流水后填写凭证返还；重复点击不重复返还，退款会使旧worker租约失效，避免迟到回执覆盖。
* 更换供方账号后，已尝试提交的旧订单暂停。恢复原Token/Key并在详情点击“恢复原单查询”才继续，禁止转到其他账号查单或重下单。
* 发布确认/反馈的不确定请求也不会自动重发。若长期没有回执，应由平台联系海讯社核查原单；系统不伪造完成状态。

媒体发布回链仅证明发稿交付，不代表搜索引擎已收录或大模型已引用。

## 官方协议

[官方开放接口文档](https://oss.ebuypress.com/doc/open.html)，请求主机固定为`https://api.haipress.com`，TLS校验开启，禁止重定向和自定义主机。公开文档版本较早，实际开户权限、字段、报价、预存政策须以海讯社给当前账号的说明及联调回执为准。

| 接口 | 用法 |
| --- | --- |
| `/api/member/user/tokenON` | 表单token/key，clientType=5；访问令牌加密缓存 |
| `/api/media/resources/list1ON` 至 `list15ON` | 15类资源目录；后台任务每页500条，全量分页同步 |
| `/api/media/resources/stateON` | 提交前复核上架状态；deleted=1正常，0删除 |
| `/api/media/order/createON` | JSON字段直接传递，ordernum为我方单号；title/content/remark分别urlencode |
| `/api/media/order/queryON` | 原单号查状态；每个订单通常间隔10分钟 |
| `/api/media/order/processON` | flag=4反馈、5确认；仅实际查到flag=3时执行 |

公开接口没有实现供方账户充值、提现或现金退款接口。本系统不显示虚构的供方余额；海讯社预存资金在供方账户维护。资源同步已升级为后台全量任务，支持断点续传、逐页租约和服务器定时命令；见[一键同步与定时任务说明](haipress-resource-sync.md)。旧单页接口仍用于兼容。

## 安装与运行

部署前备份数据库和当前代码。现有仓库包含其他二开修改，应按文件审查，不能用本次工作覆盖整个工作目录。

```sh
php scripts/install-haipress.php
php think media-press:work
```

安装脚本可重复执行，创建独立press业务表与资源同步任务表、必要列、平台/OEM菜单、原后台动态路由及商家路由。总安装脚本`install-merchant-oem.php`也会调用它。菜单包含查看、导出、保存、同步、退款、恢复查询权限；现有非超级员工需由管理员按职责授权。后续新建OEM自动获得订单/消耗菜单，不获得凭证配置菜单。

生产worker应使用现有进程管理方式常驻并自动重启；Web与worker使用同一数据库、时区、加密主密钥。Windows本地`local-start.ps1`已加入带PID核验的隐藏worker启动。单步排查用`php think media-press:work --once`。未配置且没有订单时worker不请求海讯社。

凭证和稿件预览token沿用已有AES-256-GCM凭证库，但使用独立用途命名空间。生产应保持现有`MERCHANT_CLIP_CONFIG_KEY`（至少32位）或持久化`runtime/merchant_clip_integration/master.key`，不能部署时丢失或随意替换，否则已有密文无法读取。不要把主密钥、数据库凭证或海讯社凭证提交Git。

仅有海讯社配置编辑权限的总后台账号可查看与填写 Token/Key，表单回显已保存内容并按当前输入保存；只读账号不接收明文，日志对响应中的凭证脱敏。数据库仍加密存储。仅启用接口与同步媒体资源可暂不填写域名；正式发稿前的费用核对与下单均校验本站公网访问域名，缺失时不会预扣或创建订单。该域名由平台部署者配置，不由海讯社提供，必须为真实HTTPS根域名，代理到本应用，并保证海讯社可以访问`/press-preview/{随机token}`。预览仅展示转义后的稿件，不含账号、成本或管理信息；30天过期、禁止索引、不缓存。Web访问日志应按现有安全策略限制访问和留存，避免预览链接广泛流转。

完成真实开户/API授权后可以启用并同步媒体；正式发稿前另需核对价格币种、预存条件并确认稿件预览可达。首次真实发稿仍需人工选定稿件、媒体和费用确认。没有真实凭证时页面保持“未配置/未启用”，不能将本地模拟响应当作供应商联调通过。
