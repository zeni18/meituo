# 按品牌管理的独立拓词库

用户要求将拓词从 AI 创作台拆出，建立按品牌分类的拓词库；写稿既能选词表，也能自行编写。

沿用现有品牌选择器和租户/商家/品牌隔离。侧边栏增加拓词库，按“品牌 → 词表 → 选题词/客户问题”管理，保留已有关键词分组、历史问题和生成任务。未分组和已归档分组的词条进入未归类视图，避免隐藏旧资料。

每个词表记录名称、核心词/方向，支持 AI 拓词、手工录入、文本导入、词条编辑和导出。AI 任务沿用真实队列、费用确认、价格指纹和幂等请求，成功后由用户勾选入库；不同词表允许同一词条，同一词表去重，不能自动挪走其他词表的词。

写稿工作台只保留 GEO写稿、爆文改写、批量创作三个模式；从词表侧栏选择最多100个词条加入当前主题池，或直接编写主题。词表与品牌一致；批量写稿仍每次1至3篇。关闭词表选择侧栏不丢失稿件。

复用 oem_geo_resource 的 keyword 分组及 aigc_geo_keyword 的问题记录，不迁移账本、不影响诊断问题范围。服务端验证来源任务、归属、重复和编辑并发。验收覆盖品牌隔离、归档兼容、同词跨表、选词到写稿、手动写稿以及拓词计费回归；不调用真实付费模型。
