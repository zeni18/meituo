# GEO 服务商诊断接入（2026-10-19）

对应 [API 调试文档 v1.3](https://118.89.28.187/api-docs)。本次完成接入代码与离线验收；用户尚未开通 API Key，未提交真实付费采样，平台与 OEM 监测配置保持停用。

## 开通后配置

1. 总后台 **接入能力配置 → GEO营销 → AI 可见度监测**，选择「本级自配」与「GEO服务商 API v1.3」，地址填 `https://118.89.28.187`（也接受 `/api/v1` 后缀），填写服务商 API Key。至少需要 `read`、`monitor` 权限。直接提问不需要 `provision` 权限。
2. 产品、SKU 使用已注册的 `aigc_geo / visibility_cn` 按次计费项；本地对应 ID 均为 19，界面自动读取实际安装值。按原算力市场设置平台/OEM售卖价格、商家价格并上架。目录存在或密钥保存成功不代表已经可调用。
3. 保存后点击「检查连接与余额」：查询供方 `/usage` 和 `/platforms`，核对账户余额、目录与定价配置。查询可能产生供方配置的请求费；此操作不创建诊断。
4. OEM 可在自身「接入能力配置」自配账号；借用平台账号需先由平台逐项授权，再在 OEM 选择「借用平台配置」。代理仅可取得使用授权。密钥加密保存，不下发给商家；切换供方或地址需重新填写密钥。
5. 商家进入 **GEO诊断 → 开始诊断**，可用「AI 生成诊断问题」读取企业知识及补充的行业/主营业务。默认10题，可选5/10/15题，生成前确认文本模型实际用量计费；生成后可修改，也可直接粘贴已有问题。选择检测端与平台后点「预览费用并诊断」，确认采样费用才提交。独立诊断只要求品牌名和已准备的问题，不强制填写完整企业资料。已有自动化计划可以复用保存的范围和原预算控制。

## AI 快速准备问题

先在 **接入能力配置 → AI拓词 / 文章生成 / 改写** 开通现有文本能力，并上架文本模型输入/输出售价。OEM借用平台文本能力也需显式授权。文本拓展与监测是两项独立能力，分别计费，不共用监测 API Key。

生成任务沿用 `geo_keywords` 原生文本消费与队列，用 `purpose=diagnosis`、题数、业务背景冻结本次输入。默认同时覆盖品牌认知问题和不含品牌名的行业发现问题；不编造行业事实、搜索量或排名。关闭重开弹窗查询原任务，不自动生成第二批。主动「换一批」再次确认文本费用。

诊断服务未开通时可准备问题、仅保存范围，不能提交采样。文本未开通时保留手工录入；不以免费模板冒充收费 AI 结果。异常输出保留原文与消费关联，结果不明不自动重发。

## 任务、费用与异常

- `POST /api/v1/runs` 使用直接问题模式、`collector=molizhishu`、`repeatCount=1`，并携带由持久化任务生成的固定 `Idempotency-Key`。
- HTTP 202 只表示受理。保存原任务 ID 后，每 60 秒查询一次 `GET /api/v1/runs/{id}`，最多 30 次。只有匹配任务、问题、平台的有效成功回答才入库并结算。
- 供方受理即扣款，失败/取消/缺图不自动退款，查询也可能收费。本地仍使用原算力账单与管理员配置的售价，不把供方余额或成本当作商家售价。
- 明确受理前拒绝退回商家预扣；受理后失败、查询超限、回执不一致、提交结果不明进入「待核对」，保留原预扣。不得自动创建新的付费任务。
- 管理员在「GEO任务与消耗」核对原请求编号与供方任务 ID，可在 24 小时窗口内继续查询原任务，最多再查询 30 次。此操作不重新提交采样，但供方查询费仍可能发生。超过窗口或配置/授权变化时，按原消费单人工对账。
- HTTPS 证书校验保持开启，拒绝内网/保留地址与重定向。若部署证书不受信任，应正确配置受信任证书，不关闭校验。
