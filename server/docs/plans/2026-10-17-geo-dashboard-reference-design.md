# GEO首页参考图改版

用户提供GEO推广系统截图并要求按该风格优化工作台首页。沿用已有Semi组件和专属工作台导航、返回主后台、账号与主题能力。

- 目标用户：国内商家查看内容、发布与AI可见度，并开始一键优化或独立创作。
- 领域：品牌知识、客户问题、内容资产、发布回执、平台采样、优化计划、阶段复测。
- 视觉：参考图的灰蓝工作区、白色数据面板、紫/青/蓝三张宽统计卡片；主标题18px，数字36px，正文14px，8px间距基准。深色使用同层级的暗色表面。
- 主层级：数据总览与一键GEO优化 → 三张统计卡 → AI平台统计表 → 双栏最近发布/检测问题 → 最近任务与流程入口。
- 特色：实际品牌提及数据与完整优化闭环相连；不展示参考图中的模拟排名、搜索量或第三方品牌logo。
- 保留：一键优化、优化项目、企业知识、独立创作、媒体发布、报告、任务和原流程入口；不更改计费和权限。
- 数据：新增只读dashboard汇总；所有查询绑定租户和商家。全部/今天/昨天/近7天/近30天筛选同时作用于统计和列表。文章与订单按创建时间归组，发布只计已发布订单；采样按实际观察时间统计，仅取recorded_auto。无采样时提及显示—，不作零曝光推断。
- 验证：前端类型/生产构建，读接口时间边界及隔离验证，桌面/移动、深色/浅色浏览器检查。仅使用隔离测试记录，不调用付费接口。

## 验收

- `tests/geo-dashboard.http.php`：22项通过，覆盖时间筛选、自动/人工口径、观察时间、租户/商家隔离、无付费副作用与安全回链。隔离记录已清理。
- TypeScript与生产构建通过；导航及8项主题同步契约通过。
- 桌面浅色/深色、390px手机布局已检查；手机端文档宽390px，内容宽与滚动宽一致，无整页横向溢出。
