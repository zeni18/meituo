# 接入能力配置优化

用户要求：阿里云 AccessKey ID / Secret 只填写一次、自有凭证明文回显、未修改配置时不弹切换确认。

## 行为

- 公共凭证按平台 / OEM 隔离，供 OSS、IMS、IMM 使用。新增服务默认共用，已有独立凭证保留，可手动切换来源。
- 公共凭证页面可导入本级已有服务的凭证；点击保存后生效。不自动改动现有线上配置或启用云服务。
- 配置写权限同时控制自有凭证回显。只读账号不返回明文，借权只在服务端解析上级凭证。
- 数据库存储继续使用原加密容器，公共凭证独立绑定 `aliyun`。公共凭证更新会递增依赖服务版本，沿用后台任务的版本检查。
- 表单对比初始值与当前值，只对有实际变化的配置提示未保存；还原内容后恢复为未修改。剪辑、GEO、媒体配置均适用。
- 凭证响应禁用缓存，操作日志递归移除凭证内容。

## 验证

- `tests/integration-shared-credentials.php`：事务内验证共用、独立、轮换、撤权、回显、并发版本、显式清除；回滚所有配置更改。
- `tests/integration-credentials.http.php`：独立临时账号和 OEM，验证保存、回显、只读限制、跨租户隔离、日志处理；删除测试数据。
- `tests/integration-form-state.cjs`：重复事件、实际修改、还原、勾选项、辅助搜索、保存后的基准和销毁。
- 浏览器验证无改动切换、改回原值、真实修改确认 / 取消、公共凭证导入及明文输入；不调用收费云服务。
