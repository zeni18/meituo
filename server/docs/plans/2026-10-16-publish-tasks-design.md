# 任务发布与成片库

用户要求：参照小魔推任务发布逻辑，允许选择资产中的数字人视频和AI剪辑成片；生成时选择目标成片库。用户已确认接入已有认证服务号通知。

参考实查：门店员工筛选/批量选择、任务管理抽屉；选择视频库、任务内容500字、多平台（抖音/快手/小红书）、文案库、话题库、立即/定时推送、执行情况列表。截图见 runtime/local/evidence/publish-reference。没有发送参考平台任务。

采用独立成片归档与任务模块，引用原生成功结果，不复制视频或改原生成/计费/云配置。成片库支持创建/重命名/回收、按来源筛选、已有成片批量归库；数字人提交时经附加归库字段和安全适配记录任务目的库；云剪辑在提交合成时选库。异步完成后按原始结果归档，失败不入库；未选库进入未分组。

任务保存时固定选片、文案/话题和员工平台分配快照；只接受本商家有效门店员工和可用成片。立即/定时生效，执行状态待领取/已领取/待审核/已完成/驳回，商家可取消。员工通过专属领取链接绑定服务号OpenID，链接使用随机令牌且可撤销，仅能访问该员工任务。微信服务号配置独立新增能力，沿用平台/OEM配置优先级和已有明确借权规则，不读写原框架微信配置。通知worker发送真实模板消息，保存msgid/错误，超时结果不明不自动重发；定时由worker处理。未配置或未绑定明确展示阻塞原因。

UI沿用现有明暗主题、共享下拉组件和原生侧栏，不添加大标题横幅。资产页增加成片库入口，商家侧栏增加任务发布；成片页显示库、来源、状态、预览与发布任务入口。任务页员工列表和任务记录切换，创建/执行记录抽屉参照来源。

验证：商家/租户隔离、来源归属、成功状态、回收/禁用对象、定时、重复提交、执行状态机、令牌撤销、OAuth一次性state、通知配置变更与重试。云和微信真实调用需后台配置及授权域名，使用隔离传输契约测试，不发送测试给真实员工。


## 交付与验收

已实现独立成片库、原生三种数字人成片与新增云剪辑归库、员工多平台任务分配、文案/话题快照、定时与截止、员工独立任务H5、OAuth服务号绑定、模板消息真实适配、通知worker与审核状态机。平台/OEM配置新增task_notify能力，原接口与渠道配置未修改。生产微信真实联调尚待后台配置账号、模板和公网域名；sent状态只表示微信接口受理。

测试通过：任务/成片/通知86项，生成归库适配8项，配置借权63项，原云剪辑60项。无真实微信发送或付费云生成。浏览器完整走通本地示例创建、领取、提交、审核；示例明确标注非真实AI生成/发布。员工H5实测375px，商家已检查桌面与明暗主题，未把未生效的商家窄屏视口当成通过。

实际组件保留参考的员工列表→任务抽屉→执行情况逻辑，同时提供独立选片以满足跨数字人和剪辑资产选择需求。通知配置采用与此前新增能力一致的自有优先/明确授权借权规则。凭证不在客户端或原生接口透传；生成归库适配失败不重发已提交的付费生成请求，原结果仍可从未分组整理。发布记录为员工手动发布后的审核凭据，非外部平台API回执。
