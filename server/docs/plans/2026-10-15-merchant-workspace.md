# 商家门店与素材工作区

按用户确认的原商家界面扩展：侧栏新增门店列表、素材管理（视频、图文、话题），全部工具新增排首位的门店营销分类与种草卡；恢复系统已提供但尚未显示的应用。

1. 检查本地 manifest、应用注册、租户开通与前端分类，复用原生成页面。仅在隔离预览库开通零价本地体验，不替换真实付费套餐、不调用生成服务。
2. 采用当前登录商家拥有的门店、素材、卡组合三张表；所有查询、统计、关联和写入同时约束租户与商家，文件关联只接受原上传接口的本商家文件。
3. 在原 UI 增加列表、表单、搜索、分页和回收站；使用独立商家路由与原 Vue 外壳，客户端跳转，首屏深色底；图标、字号、折叠和选中状态对齐原导航。旧借用资产路由的链接迁移到独立路由。
4. 种草卡首先支持内容组合配置；NFC、分享落地页、公开发布需按后续需求实现，不在本次声称可用。
5. 用 HTTP 验证两商家权限隔离及实际 CRUD，浏览器验证导航、表单、分类、刷新与独立路由；保留原登录保护、代理权限及应用授权限制。

实现已完成。验证细节见 `docs/merchant-oem-local.md`。完整 Vue 源码仍待提供，当前原生页面适配器依赖公开版 1.0.399 的固定导出；升级原前端前必须重新核对。
