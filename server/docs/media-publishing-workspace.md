# 媒体发布工作台（2026-10-19）

商家入口：`/ai/geo?tenant_id=1#website`。保留现有主导航、品牌选择和算力账户，按照选媒参考图组织为网站媒体、自媒体、投稿记录、我的收藏四个页签。

## 页面和数据

- 行业（自媒体为所属平台）、地区、零售价格段、名称查询、六项高级筛选、价格与名称排序均为服务端筛选和分页，不把全部目录下载到浏览器。
- 行业和地区从真实媒体目录获取全部选项，默认只显示常用按钮，可分别“展开／收起”，操作紧跟在最后一个可见选项之后；展开后平铺自动换行，收起仍保留当前选中的非常用项，不使用下拉框。
- 网站高级筛选：PC 权重、移动权重、出稿速度、周末可发、正文网址、新闻源。
- 网站媒体及网站媒体收藏增加常用“收录要求”筛选：不限／包收录／不包收录。严格使用海讯社国内软文 `searchcollint` 字段（1／0），可与名称、行业、地区、价格和其他筛选组合；缺失值及未定义的编码不归入任何承诺类别。该字段表示供方搜索收录承诺，不表示 AI 引用，自媒体不展示此筛选。
- 自媒体高级筛选：认证、粉丝区间、阅读区间、周末可发、视频投稿、供方推荐。
- 指标只投影白名单字段；无字段显示“未提供”，接口保留真实权重数值；按用户要求，页面权重 0 显示“—”，大于 0 显示数字。供方没有提供出稿率，页面不生成模拟比例。
- 出稿速度、粉丝数及阅读数代码依据[海讯社开放平台文档](https://oss.ebuypress.com/doc/open.html)转换为标签，其中粉丝数和阅读数是区间代码，不是精确人数。
- 价格支持自定义最低价／最高价，可只填一端，包含边界；金额最多两位小数，拒绝负数和反向区间。预设和自定义互斥，清除条件或重置会清除自定义边界。
- 报价是 `PressMoney` 计算的零售价格，筛选边界也以相同的整数分和上取整规则判断。底部算力以 1 元 = 100 算力展示，最终以签名报价为准。
- 收藏复用 `oem_geo_resource`，按租户、商家、品牌隔离，保留原收藏分组。新增收藏幂等；取消收藏进入既有回收站。没有新增数据库表或修改同步配置。
- 默认每页 10 条，可选 20 / 50。满页分页紧接列表，只为缺少的记录补足背景空间；空列表保留一页容量。媒体双行记录单独计算占位，避免全局脚本按默认 20 条重复撑高；其他 GEO 分页显式提供实际每页条数。
- 已选媒体跨网站、自媒体、收藏、投稿记录页签保持，最多 20 家。底栏固定在视窗下方，可查看和移除已选项。品牌切换重新建立选择状态。
- “案例”在新标签页直接打开供方提供的实际案例网址。`mediaPress/caseOpen` 按当前登录身份、品牌范围和目录版本验证媒体，按需提取海讯社预览页的“案例地址”，缓存一小时；已有直链直接使用。仅请求固定供方 HTTPS 主机与数字资源路径，不请求文章网址，不携带供方密钥；缺少或无效案例显示明确提示。

## 稿件与提交

单行“投稿”选择该媒体；底栏“核对费用”处理已选媒体。先选择或新建当前品牌稿件，可展开正文预览，再请求最新报价。确认报价仍调用原有 `quote` / `create`，保留费用确认、幂等键、预扣和回执处理。未配置公网域名时可选媒和准备稿件，不能正式提交。

原投稿记录列表、订单详情、反馈和确认发布操作继续沿用；管理端和 OEM 的订单页面未替换。
