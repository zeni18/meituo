# GEO 文章 Agent

入口：商家后台 → GEO营销 → AI创作 → 文章 Agent。

- 输入主题、目标读者和写作要求，确认本轮文本模型费用后，自动生成提纲、完整稿件和待核实事项。
- 默认引用当前品牌知识和最近 5 条事实素材；「调整创作资料」可选择最多 10 条素材、切换已配置的文本模型。
- 对话修改以当前预览稿为基础，包含手工编辑内容。新版本保留旧版本，不自动覆盖文章库。
- 点击「保存到文章库」确认入库；同一版本重复保存不会创建重复文章。修改已入库稿件使用乐观锁，避免覆盖其他窗口的修改。
- 「送媒体发布」先保存稿件，再创建媒体投稿草稿；不自动执行付费发稿。
- 刷新后恢复当前会话，创作记录可恢复其他会话。手工编辑缓存限当前浏览器会话；已入库文章保存在服务器。
- 每轮一次模型请求，最多输出 4096 Token；最多 20 轮。排队/执行中的任务或费用待核对任务不能在同一会话继续启动。没有自动重试或备用模型调用。

## 接入与计费

复用接入能力配置 → AI拓词／文章生成／改写。当前专用直连通道为 DeepSeek Flash，沿用现有 Key、授权、输入/输出 SKU、商家钱包、原消费单和 GEO 后台队列。未配置或未上架售价时按钮禁用。生成前以当前价格指纹确认，价格变更后旧确认失效。

## 数据与接口

复用 `oem_geo_job`，没有新增表或迁移。`payload_json.purpose=article_agent`，根任务 `agent_session_id=0`，后续任务保存根 ID、父轮 ID、用户需求、当前稿件和资料快照。服务端构造这些字段，普通 generate 请求不能注入 Agent 上下文。

所有接口属于 `merchantGeo`，继承原商家登录、应用授权、同源写入、租户和品牌归属校验：

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| articleAgentSessions | GET | 分页列出创作会话 |
| articleAgentView | GET | 恢复会话、任务费用、版本与已入库稿件 |
| articleAgentSend | POST | 幂等提交本轮创作/改稿 |
| articleAgentSave | POST | 确认稿件入库或更新已入库版本 |

## 验证

`tests/geo-article-agent.integration.php` 使用离线 DeepSeek 传输回调，验证真实原计费流程、归属隔离、请求幂等、当前稿件改写、价格变化、入库并发锁及异常输出保留。所有测试数据与钱包变更在事务中回滚，不访问供应商。
