# GEO 快速诊断

用户希望从诊断弹窗快速启动，并明确选择「AI 自动拓展问题，按文本模型计费」。采用现有文本任务、品牌范围、原生算力账单与监测接口，不新增钱包和模型密钥。

流程：选择当前品牌 → 使用企业知识与可补充的行业/主营业务生成问题 → 查看并修改 → 默认网页端 DeepSeek/豆包 → 直接预览采样费用 → 明确确认后启动。默认10个问题，可选5/10/15个；已有生成任务通过原任务编号继续查询，关闭重开不自动重复付费生成。更换一批需再次确认文本费用。提供直接填写问题入口。

AI 拓展与采样费用分开。模型使用现有按用量售价，生成前显示模型及输入/输出计费标准。问题生成沿用 keywords 队列，以 purpose=diagnosis 区分并冻结题数和补充背景。输出只接受可验证的 JSON 问题数组，不把失败或无法解析的回答伪装为成功。保留消费单与原始输出，不自动重发收费请求。

独立快速诊断只强制品牌名称；其他企业资料可用于提升问题质量。原优化项目的完整资料要求保留，通过显式 diagnosis_only 配置区分快速范围。AI 生成至少需要现有行业/介绍/产品/目标客户之一，或用户在弹窗提供主营业务；不编造品牌业务、地区、竞品或指数。品牌认知与不带品牌名的自然发现问题同时包含。

实施步骤：
1. 扩展现有文本任务用途、结构化结果和范围身份，验证输入与请求幂等。
2. 增加独立诊断的最小资料配置分支。
3. 更新弹窗：生成、恢复原任务、修改问题、直接预览费用，复用现有采样确认弹窗。
4. 回归任务隔离、冻结输入、费用参数、问题解析、快速范围与旧监测流程；构建后在当前未开通状态验收页面，不调用真实付费服务。

验收完成：快速诊断34项、服务商接入57项、原监测74项、自动化35项，共200项可回滚离线检查通过；前端类型检查、生产构建及5组诊断/导航/侧栏契约通过。浏览器核对默认10题、网页端2平台；切换手机端后重新选择平台，连续编辑3题×2平台实时显示6次采样。手工录入可保存范围，监测未开通仍禁止付费采样。长弹窗限制在视口内并允许内部滚动。未提交真实文本或诊断付费调用。
