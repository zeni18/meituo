# GEO 文章 Agent

用户已选择：输入创作需求后自动完成提纲和成稿，之后对话修改。

## 工作台

面向准备 GEO 内容的商家运营人员。左侧处理创作意图、品牌事实和修改对话，右侧阅读与编辑成稿。保留文章库、关键词、事实素材、图库与任务流水，旧表单工具退到辅助入口。

领域：客户问题、品牌知识、事实依据、提纲、稿件版本、内容入库、媒体投稿。配色延续产品的品牌紫、纸白、墨色、浅灰紫、事实状态绿。特征是对话版本与稿纸联动；避免统计卡片开场、整屏工具按钮及假思考动画。正文为视觉中心，14px 控件、28px 稿件标题、16px 正文，4px 间距基准；复用 Semi 控件和现有主题变量，轻边界层次。

## 执行

采用有界文章 Agent：每轮仅调用一次已配置文本模型，自动整理目标/提纲、生成完整文章、列出待核实信息。相比额外拆成规划与写作两次付费调用，更易控制费用与恢复。模型不会执行任意工具或自动付费发稿。品牌资料及选定素材由服务端校验并冻结；最多自动带入最近 5 条素材，可显式调整至 10 条。网页检索留作明确操作，未执行时不能声称已检索。

复用 oem_geo_job 作为持久化对话版本：根任务作为会话，每轮保存会话根 ID、上轮 ID、需求、上一稿件快照、资料来源。无额外数据库迁移。每轮请求幂等；服务端串行化同会话，拒绝未完成、待核对或过期版本的继续请求。最多 20 轮，每轮限制输出 4096 Token，不自动重试或切换模型。

## 确认与保存

每轮提交前展示当前输入/输出计价标准并明确确认；服务端要求计费同意和当前价格指纹。费用仍通过原消费单按实际 Token 结算。结果结构异常时保存原始结果供核查，不伪造成功。入库复用 GeoJobs::import 与 GeoWorkspace 的归属检查、幂等及乐观锁；保存前的手工编辑保留生成来源。发送到媒体发布只创建稿件，不执行付费投稿。

## 验证

使用离线模型回调与回滚事务验证归属/品牌隔离、价格变化、幂等、并发、修改上下文、结果校验、刷新恢复、编辑入库及消费归因。构建前端，浏览器验证空态、资料配置、费用弹窗、文章库入口、移动布局和滚动；不调用真实付费模型。
