# 素材文件夹拖动排序

用户确认参照左侧文件夹的行内排序模式：点击「排序」进入，右侧显示六点拖动手柄，按钮变为「保存」。拖动草稿仅存在当前页面，保存后刷新仍保留；取消恢复已保存顺序。按素材类型分别管理，全部素材和未分组为固定入口，不参加排序。

实现位于 `public/merchant/folder-sort.js` 和素材库模块。Pointer Events 支持鼠标、触控/笔，显示拖动浮层和插入线，边缘自动滚动；手柄可用方向键调整，Escape 取消当前拖动。仅允许同级先后调整，父文件夹及其子树一起显示，父子归属不变。搜索在排序模式暂停，原有搜索条件在退出后恢复。排序未保存时允许新建文件夹，元数据刷新会将新 ID 合入草稿；保存期间禁用相关控件。

新增 `MerchantWorkspaceController::folderReorder` 复用原应用授权、商家身份和同源写入检查。服务在事务中锁定当前租户、商家、素材类型的全部有效文件夹，验证提交 ID 集合完全一致且无重复，再写入既有 sort 列。不修改名称、父级和素材归属。列表增删、越权 ID、类型不匹配全部拒绝，不部分写入；不需要数据库迁移。

验收：12 项排序和手势合约、扩展后的 99 项素材库 HTTP 检查通过。浏览器实际鼠标拖动首项至末尾，保存后刷新次序保留；再次拖动带子文件夹的父项至顶部，子树跟随且刷新保留。键盘方向键、取消草稿、浅深配色及无控制台错误已验证。四个空验收文件夹已移除，未上传素材或调用 AI。

效果截图 `runtime/local/evidence/folder-sort/sort-mode-dark.jpg` 中是本次临时验收文件夹。它们已清理；实际商家有文件夹时可点击排序，无文件夹时按钮禁用。
