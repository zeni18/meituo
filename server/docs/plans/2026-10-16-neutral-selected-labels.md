# 商家端选中文字色统一

问题：剪辑单选项直接使用 --mc-accent，素材分组/页签/下拉选项等使用强调文字色；浅色主题又将原本正常的原生选中文字改成强调色。它们与选中底色绑定，造成紫底紫字。

统一语义：--merchant-selected-text 指向实时 --ia-text。选中状态仍通过主题底色、边框、下划线、单选标记及焦点环表达。饱和主题色按钮与填充页签保留 --ia-on-accent 的对比色。业务链接、标签自定义颜色、错误与状态提示不属于本次选择文字调整。

覆盖：剪辑字幕/画幅/帧率/时长/脚本步骤/分镜，素材文件夹与筛选状态，成片库分类，任务页标签和分组，员工弹窗页签，门店筛选、装修工作台页签/样式/属性导航，以及共享商家下拉与原生 Element 单选/复选/页签。平台/OEM后台主题规则不改。

采用组件源规则及共享主题语义修正，避免覆盖全部按钮或改写主题强调色。验收在深浅主题和不同皮肤下比较真实选中控件文字与普通主题文字，同时检查状态标记和主按钮对比色。

验收结果：经典深色字幕、比例、帧率选中文字均 rgb(255,255,255)，底色和边框保持紫色主题；经典浅色为普通深色主题文字。已选一键成片页签及主按钮仍保留白色对比文字。素材分组、下拉选中行及行内文字在浅色下与普通正文一致；绿色皮肤下素材分组、员工添加页签和装修样式/属性导航均为 rgb(234,246,238)，下划线及底色保持绿色。仅验证界面状态，未保存剪辑/装修、未调用生成、未提交任务。
