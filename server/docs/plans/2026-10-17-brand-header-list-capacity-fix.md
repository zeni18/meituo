# 品牌页头与分页表格空间修正

用户要求删除品牌页顶部独立留白，在所有页签保留品牌背景图，并按照每页条数预留表格背景空间。

## 原因与处理

- `renderBrandHeader` 原先对内容配置、知识库、数据统计使用 compact 分支，主动移除了封面。现在所有品牌页签共用完整横幅与品牌资料。
- 删除独立返回工具行，将返回品牌列表放进横幅左上角；编辑、企业资料、GEO 操作继续位于横幅右上角，移动端允许操作按钮换行。
- 门店嵌入品牌后覆盖了外层最小高度，其余部分表格也按实际记录数收缩。新增 `public/merchant/list-space.js`，统一识别商家端常规分页表格，根据当前每页条数、实际行高和表头高度设置表格区域最小高度。
- 只保留背景空间，不添加空数据行，不拉高真实记录，不更改统计、筛选、分页查询或权限。分页区随预留空间自然落在表格下方。
- 覆盖门店/员工、品牌内容配置/知识文档、图文及话题等成品表格、推广任务、GEO Semi 表格和现有媒体发布分页表格。没有分页的概览、卡片网格和弹窗沿用各自布局。
- 复用既有主题背景；不另写浅色背景覆盖，深色模式使用同一容量规则。

## 2026-10-18 页签切换修正

- 原因：同一品牌的页签调用完整 `render()`，清空整个品牌空间后重新请求和创建横幅、导航，造成中间高度骤减和焦点丢失。
- 现在同品牌切换复用横幅和导航节点，仅替换 `mb-brand-tabpanel`。请求期间保留原内容和高度，并设为 busy/inert，避免操作旧页；使用请求序号防止快速切换时旧响应覆盖新页。品牌数据仍在切换时刷新，统计数字原位更新。
- 内容区保留视口高度，内容配置和知识文档的加载态保留 20 行空间。跨品牌、返回品牌列表以及保存企业资料后的完整刷新保留原逻辑。
- 浏览器实测：普通点击在内容配置、门店管理、知识库、概览之间切换，导航 top 均为 419.078125px，scrollY 均为 0；快速依次点击数据统计/门店管理最终显示门店管理，只有一个内容面板。后退正确回到数据统计，位置保持不变。JS/PHP 语法检查通过。
