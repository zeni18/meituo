# 镜头素材叠放卡片

> 已按用户后续要求撤回叠图展示，当前恢复最初的简洁方形镜头按钮；素材池直接显示在所选镜头下方，见 2026-10-16-clip-original-cards.md。

根据用户提供的叠放图片参考，将每个镜头组的素材显示为独立卡片堆。

- 最多显示三层，前层为当前图片或静音视频缩略预览；空组显示暂无素材，不虚构缩略图。
- 上一张／下一张按钮显示真实页码，首尾禁用越界操作。翻页仅浏览素材，不改素材选择或云端编排顺序。
- 展开按钮选中对应镜头并显示其完整素材管理区，复用现有添加、移除、预览和前移操作；可再次收起。
- 页码和展开状态以镜头对象为单位保存在当前编辑会话中，切换镜头或重排后跟随原镜头，不写入工程配置结构。
- 镜头组仍可整组拖动或用 Alt + 左右方向键排序；翻页和展开控件从拖动命中区排除，保留普通点击选择。
- 颜色使用当前主题变量，移动端控件提供较大的触摸区域。封面固定在最前。
