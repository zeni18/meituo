# 账号内声音复刻

用户已确认中台上传样音、调用火山完成复刻、按账号保存并反复使用的流程；另已确认开通声音复刻2.0及后付费音色。本次不自动创建收费测试音色。

采用后付费自定义音色代号，避免管理员为每个用户手动购买分配槽位。预付费池适合集中采购，本期保留原有管理员音色配置兼容，不混入个人音色。平台配置新增“用户上传复刻”开关模式，个人音色不填写到公共音色 ID 列表。

个人音色与工程分离，绑定 tenant_id / user_id；保存名称、云音色代号、凭证来源指纹、状态、试听期限及同意记录。样音存放 runtime 私有目录，校验格式、真实时长、体积；上传和所有列表、查询、配音按账号鉴权。凭证变化不自动将原音色交给另一云账号。

后台队列：queued → submitting → training → ready；首次正式配音成功后 active。提交结果不确定只查询既有代号，不能自动再次训练。未正式调用的音色按云端规则展示七天期限；过期重新上传需用户主动操作。试听使用云端返回且校验域名的临时地址，不将样音公开。支持重命名，后续调用无需重复训练。

商家入口放在视频剪辑“我的音色”及配音选择器中；上传、授权勾选、进度、试听、首次启用提示与选择复用均在中台完成。首次正式配音要求明确确认后付费启用，不在试听时调用正式合成。

实施顺序：迁移及个人音色服务 → 训练/查询适配和后台处理 → 配音所有权检查 → 平台模式配置 → 商家上传与列表 → 模拟/隔离测试 → 浏览器验收 → 配置真实服务并更新教学。测试不调用真实收费接口；不扩大 OEM 借权。

官方接口：voice_clone / get_voice；新版 X-Api-Key。后付费槽位首次合成 138 元/音色；声音复刻2.0按 0.0003 元/字；试听音色七天未正式调用会被云端清理。价格和规则核对于 2026-10-20。
