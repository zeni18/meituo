# 视频剪辑侧栏行为修复 · 2026-10-23

用户反馈进入视频剪辑时左侧自动收起。旧规范的编辑器骨架要求图标栏，entries-v2.js 的 railFor(onClip) 会在进入剪辑时主动点击原生收起按钮，并在离开时尝试恢复。实际复现：从展开的工具目录进入剪辑，随后出现「展开侧栏」，is-collapsed=true。

现已删除自动点击、进入/离开恢复和关联状态记录；保留原生手动按钮，展开和收起完全由用户控制。同步修改现行规范第 8 节及 14.3 的旧要求。只提升 entries-v2.js 的缓存版本为 u1023clipnav1，未变更其余脚本缓存或剪辑业务。
