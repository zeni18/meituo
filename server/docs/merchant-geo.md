# 商家GEO工作台

2026-10-17 更新：已扩展事实素材、批量问题、AI拓词/写作/改写、网页检索、任务与原算力消耗及分级配置借权。媒体发稿支持GEO页内切换。实际模型/API凭证与价格尚需开通；国内自动监测仍待供应商正式契约。当前能力和配置步骤以[独立能力配置说明](geo-capabilities-configuration.md)为准；下文为基础阶段交接记录。

本轮修复用户反馈“没看到GEO的功能”：原商家按钮被直接拦截为“功能开发中”，旧独立控制台还显示演示用户、固定统计、模拟排名。现在使用原商家界面的`/ai/geo`工作台，左侧常用菜单中“GEO营销”位于“媒体发稿”上方。旧`/app/aigc_geo`页面及其子页面转入新工作台，不再开放演示控制台。

## 当前可用

- 品牌资料：按OEM和商家唯一保存品牌、官网、行业、介绍、产品、目标客户、竞品事实。保存检查版本冲突。
- 问题库：手工录入、编辑、搜索、分页；基于已保存品牌创建5条可编辑的本地模板，重复创建不重复添加。来源明确标注为本地模板，不冒充AI生成。
- 内容库：按客户问题编写内容草稿、查看、编辑；发送到媒体发稿时复制为不可变草稿，同一内容版本重复点击复用草稿，修改后另建新版本。
- 检测记录：保存人工观察的平台、问题、回答原文、证据链接与观察时间。标注人工记录、未自动核验，不计算模拟排名或引用率。
- 媒体发稿：联通海讯社媒体选择和费用确认。转稿不扣费、不自动下单；实际发布按海讯社回执与回链确认。
- 工作台：问题数、内容草稿数、人工证据数均来自当前商家实际数据；媒体订单数沿用本商家全部媒体发稿订单口径。

AI内容生成与豆包、DeepSeek等AI产品自动监测仍未接入，相关状态固定如实显示“未接入”。该工作台不将通用模型API回答作为消费端AI搜索曝光，也不将人工记录当成自动监测完成。本轮没有声称完整GEO自动化已交付。

## 实现与部署

`MerchantGeoService`和`MerchantGeoController`提供`/api/merchantGeo/{summary,profile,profileSave,lists,save,templates,toPress}`。所有接口要求当前商家身份及既有`merchant_marketing`授权；写入还检查POST和同源。记录按服务端tenant/user约束，不能由浏览器指定他人归属。

新增`oem_geo_profile`按商家保存档案；问题、文章、人工证据复用已有GEO表。新工作流不调用原`AigcGeoService`的模拟生成、模拟发布或模拟排名方法。原OEM/代理仍通过此前发稿订单和消耗页分级查看发稿数据，本轮没有另行开通代理编辑商家GEO资料的权限。

安装顺序：

```sh
php scripts/install-haipress.php
php scripts/install-merchant-geo.php
```

总安装脚本`install-merchant-oem.php`已包含以上步骤。安装器为当前已知Nuxt构建增加路由并修复GEO按钮；更新原前端构建后须重新核验锚点，不能直接套用未知版本。

验证：`php tests/merchant-geo.http.php`的38项检查通过，覆盖未登录、只读方法、同源、档案版本、跨商家/伪造租户、问题模板幂等、文章修改、转稿幂等和不可变版本、证据URL/时间、真实统计、不扣费不下单及旧页重定向。测试仅操作本地专用数据库，自建账号与数据已清理，无外部供应商调用。

早期版本曾核对侧栏入口、品牌表单、问题录入窗口、内容库及人工证据表单；以下为当前重构版本说明。

## 2026-10-17 Semi 专属工作台

`/ai/geo` 当前为独立全屏工作空间，包含工作台、AI创作素材库、媒体发布、数据中心四板块及参考平台子菜单。左下角返回主平台，顶部复用商家原生账号、算力与外观入口。路由、登录、平台计费、OEM/代理权限及数据归属沿用原系统。

左上角使用标准返回箭头，和底部入口一起返回 `/ai?tenant_id=…` 主后台首页。GEO 入口、旧工具入口及返回均复用原生 Vue Router，避免普通链接重载应用而再次显示启动加载页；保留新标签打开、修饰键和下载等普通链接行为。`node tests/geo-navigation.contract.cjs` 验证这一路由行为。
