# 单页 AI 创作台

商家后台 → GEO营销 → AI创作。三种模式在同一页切换：GEO写稿、爆文改写、批量创作。AI拓词已独立为按品牌管理的[拓词库](geo-keyword-library.md)。

## 完整流程

1. 选择当前品牌，确认企业知识和事实素材。默认带入最近5条，可改选最多10条。图片素材使用原图库管理；网页检索沿用原检索任务，不会默认联网。
2. 从当前品牌的拓词库选择词表，整表或勾选词题带入；也可直接编写本篇主题，不要求预先拓词。
3. 词题加入主题池后可手工添加或导入 UTF-8 文本。每行一条、最多100条；重复主题合并。最多10个相关问题可合为一个文章选题。
4. 选择文章类型、篇幅、目标读者和表达风格。高级设置包含品牌介绍、写作指令、分类、关键词分组和模型。
5. 单篇生成、参考原文改写或每批1至3篇批量写稿。提交前确认调用次数与输入/输出计价；任务在当前结果区展示状态。
6. 结果包括正文、提纲和待核查事实。可直接编辑、复制、导出、AI修改为新版本及明确确认入库。文章库、问题库、素材、企业知识、任务与原消费记录从侧栏打开，关闭后回到同一创作现场。

未提交配置和主题池按商家/品牌保存于当前浏览器会话；服务器保留已提交任务、生成版本和已入库稿件。原 #article-library、#materials、#images、#jobs 及相关工具链接兼容进入同一个工作台侧栏/模式；#keywords、#questions 和拓词工具链接进入独立拓词库。

## 计费与一致性

- 复用原 GeoJobs、GeoArticleAgent 和 DeepSeek Flash 原消费单；无新账本、无自动重复调用或发稿。
- 批量提交整体事务，队列剩余容量不足时不留半批任务。批次指纹包含全部主题，重试不得更换数量或内容。
- 每次生成最多输出4096 Token。计价指纹在提交与实际调用前复查；排队期间涨价不会直接按新价调用。
- 选题入库验证真实 AI来源任务；手工选题不伪装为模型结果。生成问题库与诊断范围分别维护，不改变已有诊断复测基准。
- 入库沿用现有幂等与文章乐观锁；从文章库加载后编辑不会覆盖其他窗口已保存的修改。

## 服务接口

`merchantGeo/studioKeywords`、`studioGenerate`、`studioSaveTopics` 为新增接口；全部继承商家登录、应用授权、同源写入、租户和品牌归属校验。结构化创作要求由服务端验证并冻结，复用原任务表，无数据库迁移。

`tests/geo-creation-studio.integration.php` 使用离线 DeepSeek 传输回调，在事务内验证真实原计费流程、整批幂等/回滚、选题来源、分类传递、权限和价格变化，不访问供应商。
