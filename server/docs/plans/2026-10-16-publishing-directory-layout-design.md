# 任务发布员工目录布局

按用户提供的小魔推截图调整任务发布页；保留此前“不添加大标题横幅”和“所有控件随系统主题切换”的约束。

- 顶部一行放所属门店、员工姓名或手机号、搜索、员工管理。
- 下方员工列表标题；右上为批量操作和任务管理。任务管理进入任务记录，记录页保留发布任务和返回入口。
- 使用单个表头：选择、员工信息、所属门店、接收任务通知二维码、员工状态、添加时间、操作。姓名与手机号并排；批量勾选移入表头，选中数量放在列表标题旁。
- 行内编辑和状态切换复用 `merchantWorkspace/storeStaffSave`，不修改后台权限逻辑；停用员工不能选入新任务。
- 二维码用项目已有 QRCode 模块对员工专属链接编码。保留复制与重置功能；生成二维码不会发送通知。本地地址提示手机访问需要正式域名。
- 新样式仅作用于任务目录；成片库、任务抽屉沿用现有样式。主题使用系统变量；窄屏下筛选换行，表格内部横向滚动。
