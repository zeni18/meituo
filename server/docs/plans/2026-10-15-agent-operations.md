# 代理经营功能

用户已确认先实现工作台、商家套餐与应用授权、算力充值流水、订单记录。继续使用原后台框架、统一登录和现有金色列表样式，不增加内容区名称横幅。

## 业务边界

- 一级代理管理本人及直属二级代理名下商家；二级代理仅本人。服务端重新计算当前关系，查询、统计、分页、筛选和写入采用同一范围。
- OEM 上架套餐是代理可开通的套餐。开通和同套餐续期更新真实会员权益，赠送算力扣减代理额度；跨套餐切换从当前时间开始。应用授权只能在 OEM 有效应用与商家当前套餐允许范围内选择，可收窄不能越权扩大权益。
- OEM 授予的是可分配的零售算力额度，不是现金，也不更改用于支付模型成本的 OEM 上游算力余额。一级向二级划拨必须扣减自身额度，商家充值原子扣减代理额度并增加真实商家余额和原点数流水。
- 手工开通/充值产生经营订单，记录应收金额，显示“未登记收款”；原支付订单继续显示真实支付/退款状态，不伪造已支付。
- 所有写入使用请求幂等键、事务与行锁；重复请求不重复开通、延期或充值，失败完整回滚。审计保留经办、归属、订单号、额度变化及权益快照。

## 实施与验收

1. 幂等迁移新增代理额度、经营操作、额度流水、商家应用白名单。
2. 完成统一范围的服务端读写和应用执行拦截，OEM 授额入口、一级下级划拨入口。
3. 接入原后台菜单及五类页面，保留既有商家与代理列表。
4. 覆盖两级关系、跨 OEM/跨代理伪造、禁用、迁移、幂等、余额守恒、套餐续期、应用实际拒绝和订单/统计隔离；真实浏览器验证布局和交互。
