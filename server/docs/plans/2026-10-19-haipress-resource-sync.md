# 海讯社全量资源同步

按用户要求把逐页同步升级为一键同步全部 15 类资源，并提供服务器定时命令。沿用平台保存的凭证、同步权限和固定供方地址。

采用数据库持久化任务，由独立资源 worker 分页执行，页面只创建任务和读取进度。浏览器关闭不终止任务。服务端和手动入口共用同一任务槽与租约，避免重入；失败页自动重试，失败类别可手动续传。配置发生变化时停止旧任务，重新开始新批次。

每页 500 条，按资源类型及供方 ID 更新本地目录，保持本地 ID 和已有订单引用。仅在某类别完整拉取成功后停用该类本批次未返回的旧资源；失败类别保留原数据。所有 15 类保存基本信息和供方业务字段；商家购买及报价仍限定已接入的国内软文、自媒体。

提供 `media-press:sync --all`（创建或续传并运行）和 `media-press:sync --work`（常驻消费手动任务）；定时任务可每日执行前者，不在本机代替生产服务器设置计划。本地启动脚本运行资源 worker。

验证覆盖分页、重复启动、断点恢复、过期租约、配置变更、空页异常、下架处理、各类字段差异及发布限制；使用本地事务和模拟供方响应，保留真实配置。通过后浏览器检查任务入口与进度，并进行真实资源同步。
