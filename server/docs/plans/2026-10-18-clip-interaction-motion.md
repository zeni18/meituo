# 剪辑页层叠镜头与素材入场

按用户提供的层叠卡片参考实现编辑器交互，沿用原有素材、工程和云任务接口。

- 分镜/脚本镜头导航显示当前卡及后方两张卡；使用镜头首个真实图片/视频作为预览，无素材时使用主题卡面。
- 点击顶卡、左右划动、上一/下一按钮、编号和方向键切换当前镜头。顶卡在 320ms 内带旋转飞出，目标卡前移。划动不重排、不删除镜头。
- 原拖动排序置于“调整镜头顺序”内，Alt + 方向键、上移/下移、复制、移除继续使用原编排逻辑和贴纸映射。
- 确认选择素材后，对新增且可见的素材从视口中部以缩放、位移及 14px→0 模糊入场，单项 520ms，依次间隔 55ms。原素材不重播；落位或离开编辑器后移除动画层并恢复原卡片。素材池滚动位置保留。
- 使用 Web Animations API；减少动态效果设置下直接切换/落位。未引入视频渲染框架、第三方动画运行时或新的计费调用。
- 卡组和动画素材使用原主题变量，卡面使用不透明 surface，避免深色下后层文字透出。390×844 下验证无横向溢出。

验证：JS/PHP 语法检查通过；`tests/clip-motion.contract.cjs` 验证阈值、方向、纵向滚动、取消、减少动态效果、键盘、连续选择和卸载清理；原镜头排序契约通过。浏览器验证按钮切换、鼠标划卡、素材选择/落位、Alt + 左方向键排序，排序后镜头原有 3 项素材仍跟随原镜头。追加单项素材时观察到只有该素材的动画层，运行中含 blur(3.71186px) 及平移/缩放矩阵，落位后动画层为 0，3 项原卡均可见。

浅色、深色和手机端截图保存在 `runtime/local/evidence/clip-layered-deck-*.png`，素材飞入截图为 `clip-material-fly-in.png`。本地临时素材验证后已清理，测试工程未保存或调用云端生成。
