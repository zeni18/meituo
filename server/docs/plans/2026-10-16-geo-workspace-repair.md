# GEO入口及业务工作台修复

延续已确认的国内商家、代理/OEM方向及GEO调研方案。本次用户反馈“没看到GEO的功能”，根因是商家GEO按钮在打包脚本中直接返回“功能开发中”，原独立GEO页仍展示演示身份、固定统计和本地模板结果。

修复采用现有商家界面增加`/ai/geo`，替换原GEO按钮，原`/app/aigc_geo`页面重定向，避免继续展示演示控制台。品牌资料新增按tenant/user唯一的档案；问题、文章、人工检测证据复用已有GEO表并严格按当前商家读写。提供品牌表单、问题手工录入与可编辑问题模板、文章保存与编辑、人工回答证据、真实数量汇总和送海讯社发稿草稿。沿用原主题和现有账户授权。

问题模板明确标注“本地模板”，文章不使用固定AI生成模板冒充真实生成；监测明确标注尚未接入自动采集，人工证据不作为自动监测排名或引用率。原GEO服务的模拟发布方法不用于新流程，只有海讯社确认回链才算实际发布。模型生成和自动AI产品监测需后续配置真实通道；本轮不虚构对接完成。

验证：跨商家/跨OEM读取和修改拒绝、伪造品牌/文章ID拒绝、问题模板持久化、证据统计口径、文章到发稿草稿幂等、无额外扣费；浏览器点击GEO入口后能使用五个业务页面并在右侧栏保留。

结果：38项检查通过，测试数据已清理；桌面入口及各表单已核对。补充把GEO入口前移至常用导航，避开原侧栏底部难以发现的问题。完整状态、部署与限制见[工作台说明](../merchant-geo.md)。
