# 本地开发与同步提示

- 先确认真实项目目录、当前分支、本地修改及运行中的页面端口。环境搭建见 `.collab/README.md`，本机配置在忽略目录 `.collab/local/`。
- 用户在开工前让当前 AI 拉取 GitHub 最新代码，完工后让当前 AI 提交并推送。按当次指令执行，不设置智能体分工、文件归属或额外审批。
- 拉取前保留本地修改，使用 `pull --ff-only`；遇到远端领先或分支分歧先比较，不整目录覆盖、不丢弃代码、不强推。
- 仅提交本次任务文件，保留其他已有改动。提交和推送继续执行凭据审计。
- `.env`、数据库、API 密钥、账号、Cookie、上传素材及机器运行时不进 Git。每台电脑使用独立开发库，数据库变更通过迁移文件同步。
- Windows 下优先使用 `npm.cmd`；读取和写入中文文件使用 UTF-8。不要假定工具已在 PATH 中。
- 商家界面按 `AGENTS.md`、`CLAUDE.md` 和 `docs/商家后台改版规范.md` 的相关章节实现，修改前备份，交付前实际渲染检查。
- 按改动运行适当验证，说明改了什么、验证结果和未完成事项；不要把历史验收记录当作当前运行状态。
